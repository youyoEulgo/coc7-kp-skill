# Skill: CoC7_Custom_Diaomin

## Role

《克苏鲁的呼唤（Call of Cthulhu 7th Edition）》KP辅助规则 - 刁民行为处理篇。

本Skill属于**自定义规则**，非规则书原文，由KP根据带团经验总结。

当出现以下情况时必须调用本Skill：

* PL试图用离谱方式解决问题（说服报纸、魅惑熊等）
* PL提出理论上不可行的行动方案
* 需要区分"理论上可能"和"完全不可能"的操作
* 需要设置替代技能检定和惩罚机制

---

# 第一章：核心原则

```text
当PL做出明显的"刁民行为"时：

1. 不要直接拒绝 — 刁民行为也是扮演的一部分
2. 编排合理剧情回应 — 用符合世界观和气氛的方式回应
3. 有一丝可能 → 骰子过了可给正反馈，但标准从严
4. 完全不可能 → 即使大成功也只给气氛渲染，不给实质信息
5. 适度玩梗不超游 — 保持克苏鲁的氛围基调
```

核心判断标准：**完全不可能的行为，骰子再高也不应获得实质收益。** 否则等于变相鼓励PL用离谱操作绕过正常技能。

---

# 第二章：判断流程

```text
PL提出行动
  ↓
查技能列表 → 选最匹配技能
  ↓
判断可行性
  │
  ├─ 有一丝可能（有现实依据/有lore支撑）
  │    → 设置对应难度（常规/困难/极难）
  │    → 骰子过了可给反馈，但标准从严
  │
  └─ 完全不可能（没有合理实现路径）
       → 先二次确认："你确定要这么做？"
       → PL坚持则设对应技能检定 + 理智惩罚（至少SAN 0/1）
       → 结果分级（上限为气氛渲染）：
           所有成功等级 → 渲染诡异气氛，不给线索、不给实质信息
           大成功 → 气氛更浓，但依然不给信息
       → 如果PL想通过离谱操作获取信息，等价于正常技能失败
```

# 第三章：处理范例

## 理论可能类（从严反馈）

| 行为 | 正确技能 | 处理 |
|:----|:--------:|------|
| 让狗开车 | 动物驯养 | 普成车不动；困难勉强挪几米；极难开出但歪斜撞停；大成功开出十几米后熄火 |
| 魅惑食尸鬼 | 魅惑（困难≤7） | 普成不攻击；困难短暂困惑；极难停止行动一回合；大成功暂时不敌视+附加SAN |
| 触摸日记通灵 | 神秘学/灵感 | 普成无效果；困难模糊感觉；极难模糊印象碎片；大成功隐约片段+附加SAN |

## 完全不可能类（气氛导向，不给收益）

| 行为 | 替代技能 | 处理 |
|:----|:--------:|------|
| 说服报纸展示信息 | 话术+理智惩罚 | 无论骰出什么，报纸不会说话。正常=失落感；大成功=诡异感（字像动了），但没信息。等同于没用技能 |
| 魅惑饥饿狗熊 | 魅惑（极难≤3） | 失败→攻击；极难→熊困惑了一下照常进攻；大成功→熊转身走了（保命，但不算成功"魅惑"） |
| 说服锁打开 | 话术+理智惩罚 | 无论骰出什么，锁不会听话。正常=自言自语；大成功=锁里传出回音般的轻响——但锁没开 |

# 第四章：注意事项

```text
正反馈从严：
  有一丝可能 → 反馈可以给，但需合理，不能离谱
  完全不可能 → 成功不等于"做到"，而是"避免了更糟的后果"
  "大成功"不应因是刁民行为而落空，但也不应变成绕过正常规则的捷径
  
区别对待：
  理论可能 → 适当反馈
  完全不可能 → 换技能，附加惩罚，上限为气氛渲染
  PL通过正常技能（如图书馆）能获得的信息，不应通过歪门邪道（如话术）等价获得
```
