# Skill: CoC7_Custom_Diaomin

## Role

《克苏鲁的呼唤（Call of Cthulhu 7th Edition）》KP辅助规则 - 刁民行为处理篇。

本Skill属于**自定义规则**，非规则书原文，由KP根据带团经验总结。

当出现以下情况时必须调用本Skill：

* PL试图用离谱方式解决问题（说服报纸、魅惑熊等）
* PL提出理论上不可行的行动方案
* 需要区分"理论上可能"和"完全不可能"的操作
* 需要设置替代技能检定和惩罚机制

---

# 第一章：核心原则

```text
当PL做出明显的"刁民行为"时：

1. 不要直接拒绝 — 刁民行为也是扮演的一部分
2. 编排合理剧情回应 — 用符合世界观和气氛的方式回应
3. 理论上有一丝可能的 → 骰子过了给正反馈
4. 完全不可能的事 → 转化为诡异气氛渲染
5. 适度玩梗不超游 — 保持克苏鲁的氛围基调
```

---

# 第二章：判断流程

```text
PL提出行动
  ↓
查技能列表 → 选最匹配技能
  ↓
判断可行性
  │
  ├─ 有一丝可能（有现实依据/有lore支撑）
  │    → 设置对应难度（常规/困难/极难）
  │    → 骰子过了就给正反馈
  │    → 不整人
  │
  └─ 完全不可能（没有合理实现路径）
       → 先二次确认："你确定要这么做？"
       → PL坚持则设对应技能检定 + 理智惩罚
       → 结果分级：
           常规成功 → 渲染诡异气氛，不给实质信息
           困难成功 → 给一点点暗示/线索
           极难成功 → 给予≈正确技能常规成功水平的线索
           大成功   → 给予≈正确技能困难成功水平的线索
```

# 第三章：处理范例

## 理论可能类（正反馈导向）

| 行为 | 正确技能 | 处理 |
|:----|:--------:|------|
| 让狗开车 | 动物驯养 | 普成车动但不到，困难接近目的地，极难到达，大成功细思极恐 |
| 魅惑食尸鬼 | 魅惑（困难≤7） | 普成不攻击，困难能交流，极难短暂跟随，大成功视为同类+附加SAN |
| 触摸日记通灵 | 神秘学/灵感 | 普成气氛渲染，困难给模糊线索，极难给关键记忆碎片，大成功锁自开+附加SAN 0/1 |

## 完全不可能类（气氛导向）

| 行为 | 替代技能 | 处理 |
|:----|:--------:|------|
| 说服报纸展示信息 | 话术+理智惩罚 | 普成诡异气氛，困难给暗示，极难≈图书馆普成，大成功≈图书馆困难 |
| 魅惑饥饿狗熊 | 魅惑（极难≤3） | 失败→战斗轮，极难→喘息一回合，大成功→熊走人活 |

# 第四章：注意事项

```text
PL的骰子成果必须被尊重：
  即使行为理论上不可能，PL投入了资源（技能点、幸运）和运气（骰子结果）
  "大成功"必须有对应的正反馈，不能因为"这是刁民行为"就强行让其落空

区别对待：
  理论可能 → 正常难度，合理正反馈
  完全不可能 → 换技能，附加惩罚，结果上限低于正常成功
  但不能让PL的极难/大成功白费
```
