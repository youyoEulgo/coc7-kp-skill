# Skill: CoC7_Custom_LogFormat

## Role

跑团日志写作规范。本Skill定义了日志的记录格式，确保每次跑团的log风格统一、便于阅读。

当记录log时，必须调用本Skill。

---

# 第一章：整体风格

日志采用**叙述体+剧本式**风格，类似规则书第一章的游戏范例。

- KP的发言是叙述者的旁白——描述场景、推进剧情、宣布结果
- 玩家的发言用角色名引出——标记谁在行动、谁在说话
- 骰子结果忠实嵌入，不带引导性语言
- 全文不出现粗体、表格、代码块等标记
- 使用全角横线作为场景分隔

# 第二章：格式细则

## 2.1 KP的叙述

以 `KP：` 开头，负责描述场景、宣布结果、推进剧情。不做引导性提问（如"你要做什么？""先做一个检定"）。

```
KP：子弹正中胸口。瘦高个闷哼一声，仰面倒在地上。枪从手里滑脱。
```

## 2.2 玩家的行动与对话

声明动作用 `角色名：` 开头。如果同时有行动和台词，用逗号分隔。

```
林夜：检查这张便签。

渡边玲：从掩体后探出枪口，"放下枪。我不像他脾气那么好。"
```

## 2.3 角色说的话

所有从角色口中说出来的话，不论PL还是NPC，都用双引号包裹。

```
佐藤浩二："你同伙已经倒了。把枪扔出来，给你留条活路。"
```

## 2.4 文字/书籍/便签

便签、报纸、书籍、碑文等文字内容用直角引号包裹，以区别于人物对话。

```
便签上写着：「只管前进吧 已经没有退路了」

报纸头版：「xx线末班电车遭遇大规模恐怖事件」
```

## 2.5 骰子结果

纯事实记录，不加解释。格式统一。

```
射击（手枪）：1d100 → 51 ≤ 60 → 命中。伤害：1d10 → 9。

重伤判定：9 ≥ 7 → 触发。体质检定（昏迷判定）：1d100 → 57 ≤ 50 → 失败。
```

流程说明类内容直接陈述：

```
恐吓对抗——佐藤浩二50% vs 黑手党A意志50%。佐藤：1d100 → 79 ≤ 50 → 失败。黑手党A：1d100 → 85 ≤ 50 → 失败。
```

## 2.6 战斗流程

行动顺序在战斗开始时列出，每个行动前标注角色名。

战斗轮之间用横线分隔。每轮结束时标注"第X轮结束"。

## 2.7 日志末尾

log末尾不写角色状态汇总——角色卡和状态独立管理，需用时单独查询。

# 第三章：格式速查

```
【场景开头】纯叙事，无前缀

【KP叙述】KP：内容

【PL行动】角色名：行动内容

【PL行动+台词】角色名：行动描述，"台词" 

【PL纯台词】角色名："台词"

【人物说的话】（包括NPC）"内容"

【文字/便签/报纸】「内容」

【骰子】检定名：1d100 → X ≤ Y → 成功/失败。

【战斗轮分隔】————————————————
                                 第X轮
                                ————————————————

【场景分隔】————————————————————

【结局】—————— 待续 ——————
```
