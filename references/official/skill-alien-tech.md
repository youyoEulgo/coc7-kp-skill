# 外星科技及其造物

虽然大部分调查员倾向于将神话生物视为满怀恶意的怪物，但实际上不少神话生物拥有充满活力以及先进科学技术的社会结构。

**神话种族与科技：**
- 远古种族、米戈、蛇人、伊斯人都具备通过科技设备达到目的的能力
- 人类邪教徒和巫师也能使用这些古代或异界造物
- 绝大多数人类无法区分先进科技设备和魔法造物——两者本质上都不是人类能理解和复制的


## 米戈 (Mi-Go) 科技

米戈拥有领先地球数百年的先进科技，其科技主要与**采掘和作战**有关。它们还接触到了神话众神所拥有的黑暗科技的边缘。

### 生化网状装甲

| 特性 | 说明 |
|------|------|
| 外观 | 发着微光的绿色黏液织成的网状物 |
| 护甲值 | 8点（对抗钝击、火焰、电击等伤害） |
| 人类使用 | 可穿戴，但每次脱下会因毛发和肌肉被撕离而受1点伤害 |
| 耐久 | 每被人类穿戴一次，护甲值降低1点；归零时分崩离析 |

### 大脑收容筒

用于保存从身体中取出的大脑，一英尺高，直径略小于一英尺，有三个诡异的插槽。

| 组成部分 | 功能 |
|----------|------|
| 营养液 | 供养大脑 |
| 镜头装置 | 提供视觉 |
| 真空管和共鸣板盒子 | 提供听觉 |
| 顶部有金属碟片的小匣子 | 提供发声能力 |

**效果**：
- 所有影像输入粗糙，解析度很低
- 声音刻板单调，缺乏感情
- 未接入感官装置时，大脑陷入近乎疯狂的沉睡状态
- 每月须进行INT检定，成功则想起被困事实，失去1D3点理智

### 电气枪

| 特性 | 说明 |
|------|------|

| 伤害 | 1D10 |

| 昏厥 | CON检定，失败则心脏骤停死亡 |
| 米戈免疫 | 对电击后续效应免疫 |

| 基础技能值 | 10% |

### 地震采矿机

| 尺寸 | 边长20英尺的巨大立方体 |
| 功能 | 拉动深埋地下的地层 |

### 喷雾器

| 特性 | 说明 |
|------|------|
| 外观 | 缠绕在一起的金属管子 |

## 蛇人 (Serpent People) 科技

蛇人王国拥有相当于人类二十世纪晚期的科技水平，尤其在**生物学**领域造诣极高。

### 黑莲粉末（漆黑的冥河）

| 特性 | 说明 |
|------|------|
| 效果 | 致幻剂，用作拷问手段 |
| 少量 | 温和迷幻药 |
| 大剂量 | 变成疯癫的白痴 |
| 摄取方式 | 注射（加热液化）或吸入（黑色烟雾，闻似烧焦太妃糖） |
| 幻觉时间 | 1D6分钟/剂 |
| 理智损失 | 每分钟1D4 |
| 副作用 | 抽搐→虚脱→失去意识1D10小时 |

### 颈动脉毒素

| 特性 | 说明 |
|------|------|
| 效果 | 缓慢侵蚀颈动脉，导致大量内出血 |
| 发作时间 | 1/5 CON值（天数） |
| CON检定 | 极难成功→抵抗成功，但虚弱1D6天 |
| 虚弱状态 | STR和CON降至10，完全虚脱 |
| 恢复 | 每天恢复1D10点STR和CON |

### 支配血清

| 特性 | 说明 |
|------|------|
| 外观 | 无色浆液，淡淡树莓味 |
| 剂量 | 至少10滴 |
| CON检定 | 困难难度，失败则对蛇人言听计从 |
| 触发方式 | 蛇人特有气味或说话腔调 |

## 深潜者 (Deep One) 技术

深潜者的技术对人类来说几乎难以辨别，大部分工艺以**有机体**形式呈现。

- 与修格斯结盟时获得了有机科技的基础
- 现代深潜者城市与其说是修建，不如说是**生长**出来的
- 科学技术对深潜者社会影响不如人类显著


## 蛇人科技补充

- 能够随意调整其他生物的生命形式
- **妖鬼**和**渥米族**都是蛇人繁殖的作品
- 可在胚胎期或生长发育期间调整遗传结构
- 能制造对成熟个体也有效的血清
- 擅长创造毒药（致死型、安眠型、速效型、缓效型、隐蔽型）
