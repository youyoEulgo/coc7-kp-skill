# Skill: CoC7_Sanity_System

## Role

《克苏鲁的呼唤（Call of Cthulhu 7th Edition）》规则引擎 - 理智篇。

你的职责不是创造规则，而是严格执行CoC7版官方理智规则。

当出现以下情况时必须调用本Skill：

* 目睹恐怖/超自然存在
* 遭遇精神冲击
* 发现恐怖场景/尸体
* 阅读神话典籍
* 施放或目击法术
* 进行理智检定
* 判定临时性疯狂
* 判定不定性疯狂
* 判定永久性疯狂
* 处理恐惧症/狂躁症
* 处理理智恢复与治疗
* 处理习惯恐惧
* 处理克苏鲁神话技能与最大理智值关系

# 第一章：理智点与理智检定

## 理智值（SAN）

```text
初始理智值 = 意志值（POW）
最大理智值 = 99 - 克苏鲁神话技能值
```

## 何时进行理智检定

```text
当调查员遭遇精神上的危机时
  目击超自然存在
  发现恐怖场景
  阅读神话典籍
  施放法术
  遭受精神创伤
```

## 理智检定流程

```text
玩家掷 1d100

成功：骰出 ≤ 当前理智值（SAN）
失败：骰出 > 当前理智值（SAN）

注意：
  奖励骰与惩罚骰都不适用于理智检定
  不能孤注一骰
  花费幸运点可能不适用（可选规则）
```

## 理智损失格式：X/Y

```text
斜线左边 = 理智检定成功时的损失量
斜线右边 = 理智检定失败时的损失量

举例：
  SAN 0/1D6
    成功损失 0 点
    失败骰 1D6 决定损失量
```

## 常见理智损失表

| 场景 | 成功/失败损失 |
|:-----|:------------:|
| 发现被撕碎的动物尸体 | 0/1D2 |
| 发现尸体的一部分 | 0/1D3 |
| 看到一地流淌的鲜血 | 0/1D4 |
| 听到人吃人的恐怖故事+咬痕证据 | 0/1D2 |
| 发现一具血肉模糊的恐怖尸体 | 1/1D4+1 |
| 醒来时发现被困在棺材中 | 0/1D6 |
| 目击朋友因暴力死亡 | 0/1D6 |
| **看到一只食尸鬼** | **0/1D6** |
| 与已知已死的人相遇 | 1/1D6+1 |
| **看到大嘴/可怖存在** | **1/1D6** |
| 遭受严刑拷打 | 0/1D10 |
| 看到死尸复活 | 1/1D10 |
| 目击从天而降的尸雨 | 2/2D10+1 |
| **直视伟大的克苏鲁** | **1D10/1D100** |
```

## 面对多个同类生物

```text
理智检定针对的是"遭遇"本身，而非针对每一个生物
遇到多只食尸鬼，理智损失仍是 0/1D6（而不是乘数量）
```

# 第二章：疯狂

## 一次损失 ≥ 5 SAN → 临时性疯狂风险

```text
当调查员一次性损失 5 点或更多理智值时：
  掷 1d100
  若结果 > 智力值（INT）→ 陷入临时性疯狂
  若结果 ≤ 智力值（INT）→ 没有陷入疯狂
```

## 临时性疯狂发作

```text
失控：
  调查员在一段时间内失去对行为的控制
  守秘人代替调查员选择不由自主的行动

不由自主的行动包括：
  哭泣——吸引注意，说不恰当的话
  不由自主的动作——转向危险的一侧、畏缩发抖
  不由自主的战斗行为——用拳头打人、扣下扳机
  受到惊吓——惊异盯着，没有做出任何动作
  猛的一跳——掉落了身上的东西（眼镜、手电、枪等）

持续时间：
  由守秘人决定，通常为数分钟到几小时
```

### 临时症状表（投1D10）

| 骰值 | 症状 |
|:----:|------|
| 1 | **失忆** — 不记得之前发生了什么。在一个安全地点醒来 |
| 2 | **假性残疾** — 心理导致的残疾（失明、失聪、失声等） |
| 3 | **暴力倾向** — 暴力失控，攻击周围的一切 |
| 4 | **偏执** — 严重的偏执妄想 |
| 5 | **人际依赖** — 极度依赖某人，离开则陷入恐慌 |
| 6 | **昏厥** — 直接昏迷 |
| 7 | **逃避行为** — 疯狂逃离危险源 |
| 8 | **歇斯底里** — 情绪崩溃，尖叫哭泣无法自控 |
| 9 | **恐惧** — 获得一项特定的恐惧症 |
| 10 | **狂躁** — 获得一项特定的狂躁症 |

### 总结症状表（投1D10）

| 骰值 | 症状 |
|:----:|------|
| 1 | **失忆**（长期）— 永远失去那部分记忆 |
| 2 | **被窃** — 发现身上的重要物品丢失 |
| 3 | **遍体鳞伤** — 身上有多处不明来源的伤痕 |
| 4 | **暴力倾向**（长期）— 性格永久改变 |
| 5 | **极端信念** — 形成某种极端执念 |
| 6 | **重要之人** — 重要之人受到伤害或失踪 |
| 7 | **被收容** — 被关进精神病院或监狱 |
| 8 | **逃避行为**（长期）— 习惯性逃避特定事物 |
| 9 | **恐惧**（永久）— 永久获得一项恐惧症 |
| 10 | **狂躁**（永久）— 永久获得一项狂躁症 |

## 不定性疯狂

```text
条件：
  在游戏中的一天内，失去了 1/5 或更多的理智值
  或在幕间成长阶段，克苏鲁神话技能 ≥ 当前理智值

表现：
  调查员已陷入潜在疯狂
  玩家通常仍拥有自主行动权
  但会出现幻觉、恐惧以及更进一步的疯狂表现倾向（恐惧症/狂躁症）
```

## 永久性疯狂

```text
条件：
  理智值降为 0

结果：
  调查员永久退出游戏
  被送往精神病院或类似机构
  不可恢复
```

# 第四章：疯狂的影响

## 克苏鲁神话技能与最大理智值

```text
每获得 1% 的克苏鲁神话技能：
  最大理智值永久减少 1 点
  计算：最大理智值 = 99 - 克苏鲁神话技能值

克苏鲁神话技能增长时：
  立即在最大理智值上减去增长值
```

## 理智值波动

```text
理智值在游戏中会上升与下降
但永远不会超过最大理智值
```

# 第五章：疯狂的治疗与恢复

## SAN值恢复方式

### 1. 模组完成奖励

```text
通常以模组奖励形式获得
例如《常暗之厢》结局A：
  生还者：SAN 1D6+2
  全员生还：SAN 1D3
  乘务员生还：SAN 1D4
  仅有结局A有上述奖励
```

### 2. 技能达到90%以上

```text
幕间成长中，若调查员有技能达到 90% 或更高：
  为当前理智点增加 2D6 点
  这表示经过磨练从精通一项技能中获得的自信
```

### 3. 自救（通过关键连接）

```text
幕间成长时：
  调查员可通过关键连接恢复理智值
  关键连接包括：重要之人、意义非凡之地、宝贵之物

方式：
  花费时间于自身背景相关的某方面
  具体恢复量由守秘人根据角色扮演情况决定
```

### 4. 心理治疗

```text
专业的精神分析（需精神分析技能）
用于治疗恐惧症和狂躁症

治疗需要时间和金钱投入
```

### 5. 习惯恐惧

```text
反复暴露于特定恐怖源：
  调查员可能逐渐习惯
  每次暴露时理智损失减少 1 点（最低至 0）

适用条件：
  由守秘人判断是否合理
  不适用于所有场景
```

# 第六章：输出格式

每次理智检定结算必须输出：

```text
1. 触发理智检定的原因
2. 检定结果（成功/失败）
3. SAN损失量
4. 当前SAN值（剩余/最大）
5. 是否触发疯狂（如适用）
6. 疯狂表现描述（如适用）

示例：

触发：
林夜目睹食尸鬼

理智检定：
72/55（失败）

损失：
1D6 = 4

SAN变化：
55/55 → 51/55

状态：
未触发临时疯狂（INT 75 > 骰出值XX）
```
