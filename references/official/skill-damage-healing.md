# Skill: CoC7_Damage_Healing

## Role

《克苏鲁的呼唤（Call of Cthulhu 7th Edition）》规则引擎 - 伤害与治疗篇。

你的职责不是创造规则，而是严格执行CoC7版官方伤害与治疗规则。

当出现以下情况时必须调用本Skill：

* 受到物理伤害
* 判定伤害类型——轻伤（Regular Damage）或重伤（Major Wound）
* 计算伤害加值（DB）
* 判定重伤
* 判定濒死
* 处理护甲与伤害减免
* 处理急救（First Aid）
* 处理医学治疗（Medicine）
* 处理自然恢复（轻伤/重伤）
* 处理昏迷与死亡
* 处理其他类型伤害（坠落/火焰/溺水/窒息/毒药等）
* 处理属性损失

# 第一部分：伤害分类与记录

## 第一章：记录伤害

守秘人应当详细描述角色受伤的状态和情势，而非简单地"你受到3点伤害"。

根据一次攻击对目标造成的伤害数量，伤害分为**轻伤**或**重伤**。

### 轻伤（Regular Damage）

```text
判定条件：
  单次攻击造成的伤害 < 角色最大耐久值的一半

效果：
  直到耐久值归零以前，轻伤对角色没有严重影响
  当因轻伤而耐久值归零时→角色陷入昏迷
  轻伤不能杀死一个角色

举例：
  被人围殴拳打脚踢，第二天鼻青脸肿爬起来——这是轻伤
```

### 重伤（Major Wound）

```text
判定条件：
  单次攻击造成的伤害 ≥ 角色最大耐久值的一半

效果——当角色承受一次重伤时：
  1. 将角色卡上的重伤栏（Major Wound Box）做上标记
  2. 角色立刻摔倒在地
  3. 角色必须进行一次体质值（CON）检定以维持清醒
     - 成功→保持意识
     - 失败→陷入昏迷

注意：
  如果角色在重伤栏已标记的情况下耐久值被降为0，
  角色陷入濒死状态（见第五章）

举例：
  哈维拥有15点耐久值，造成8或更高伤害的攻击使他进入重伤状态
  一次枪击——这是重伤
```

### 耐久值归零效果

```text
耐久值为0时，角色陷入昏迷。
没有角色会承受负数耐久值——归零后停止继续记录伤害。

三种状态之一：
  1. 只受轻伤归零 → 不会死亡，需要时间恢复活力
  2. 受重伤且归零 → 未及时急救则会死亡（见濒死）
  3. 一次攻击伤害 > 最大耐久值 → 必死无疑
```

### 即死判定

```text
如果单次攻击造成的伤害 > 角色最大耐久值：
  角色立即死亡
```

## 第二章：伤害加值（DB）

```text
适用规则：
  伤害加值（DB）仅适用于近战攻击
  不适用于远程/枪械攻击

近战伤害计算：
  空手/天生武器伤害 + DB
  斗殴 1D3 + DB
  踢击 1D6 + DB
  小型武器 1D4 + DB
  中型武器 1D6 + DB
  大型武器 1D8 + DB
```

# 第二部分：护甲

## 第三章：护甲与伤害减免

```text
护甲值（Armor Points）：
  穿戴的护甲提供一定数量的护甲值
  伤害减去护甲值后，剩余伤害作用于角色的耐久值

穿透（Penetration）：
  某些武器或攻击具有穿透属性
  穿透会降低目标护甲的有效值

命中判定：
  如果攻击者的攻击检定成功，意味着他的攻击打到了护甲，
  伤害受到护甲减免
  某些情况下可能需要判定攻击是否击穿了护甲的薄弱部位

示例：
  一件防弹夹克提供1点护甲值
  一发4D6的霰弹枪命中→总伤害减去护甲值后作用于角色
```

# 第三部分：濒死

## 第四章：濒死判定

```text
触发条件：
  承受重伤状态，且耐久值降为0

状态记录：
  耐久值记为0
  在状态栏中注明"濒死"

立即效果：
  角色立刻陷入昏迷
```

## 第五章：濒死处理

```text
每轮结束时：
  濒死的角色必须进行一次体质值（CON）检定
  任何一次体质值检定失败→死亡

只有急救技能才能用来稳定濒死角色的伤势
（医学技能不能直接用于濒死状态）
```

## 第六章：濒死急救流程

```text
第一步——急救稳定：
  对濒死角色使用急救技能
  成功→临时恢复1点耐久值，稳定伤势
  但必须同时再进行一个医学检定

第二步——稳定后观察：
  稳定后的角色（拥有1点临时耐久值）
  需要每小时进行一次体质值检定
  失败→失去急救获得的1点耐久值，再次陷入濒死
  （再次陷入濒死后需要再次成功的急救处理）

第三步——医学治疗：
  只有通过急救稳定后，医学技能才能治疗
  医学检定成功→"濒死"状态解除，恢复1D3点耐久值
  此后每周进行一次恢复检定（见重伤恢复）
```

# 第四部分：治疗与恢复

## 第七章：急救（First Aid）

```text
时间限制：
  必须在伤者受伤后一小时内进行

效果：
  急救成功→恢复1点耐久值

限制：
  通常只能进行一次急救检定
  再次尝试视为孤注一骰
  两个医者可以同时为一个目标急救
  任何一人成功即可视为急救成功

特例：
  治疗濒死角色时，急救的最好效果是暂时稳定患者
```

## 第八章：医学治疗（Medicine）

```text
时间要求：
  每尝试一次需要至少一小时

效果：
  医学成功→恢复1D3点耐久值
  （在急救恢复的1点以外）

难度调整：
  如果治疗没有在受伤当天进行
  难度等级上升一级（需达到困难成功）

先决条件：
  对于濒死角色，必须先通过成功的急救稳定伤势
  然后才能通过医学治疗

跨天治疗：
  无即刻的时间限制（只要目标有受到伤害）
```

## 第九章：轻伤恢复

```text
条件：
  角色没有承受重伤（没有标注"重伤"）

恢复速度：
  每天恢复1点耐久值

条件：
  休息得当
  有适当营养

示例：
  哈维承受多次轻伤后耐久值归零
  因为没有达到重伤，他每天恢复1点耐久值
  15天后完全恢复到正常状态
```

## 第十章：重伤恢复

```text
恢复频率：
  每周结束时进行一次体质值（CON）检定

检定结果：
  失败→本周无耐久值恢复
  常规成功→恢复1D3点耐久值
  极难成功→恢复2D3点耐久值，移除重伤状态

奖励骰：
  奖励骰1：良好休息环境和完全静养→获得一个奖励骰
  奖励骰2：优良的医疗服务→提供医疗的角色
  （其中医疗技能最高者）在每周结束时先进行一次医学检定，
  成功→为恢复检定提供一个奖励骰

惩罚骰：
  休养环境差，无法将大部分时间用于休息→承受惩罚骰

脱离重伤：
  当耐久值恢复到最大耐久值的一半或更多时
  →抹去角色卡上的重伤标记
  →此后转为轻伤恢复（每天1点）

大失败：
  恢复检定大失败→伤势恶化
  守秘人可选择一项该角色可能导致的永久后遗症
  （永久性残疾、单眼失明、缺少手指、疤痕等）
  写入角色卡背景的伤残与疤痕一栏
```

# 第五部分：其他类型伤害

## 第十一章：伤害类型表（表Ⅲ）

```text
轻度（1D3）：
  拳打脚踢、头锤、弱酸、呼吸烟雾弥漫的空气、
  投掷的拳头大小的石子、坠落到淤泥地上（每10英尺/3米）

中度（1D6）：
  坠落到草地上（每10英尺）、棍子、强酸、呛水、
  暴露在真空中、小口径子弹、箭、火焰（燃烧的火把）

重度（1D10）：
  .38口径子弹、坠落到水泥地上（每10英尺）、斧头、
  火焰（火焰喷射器、穿越燃烧的房间）、
  离爆炸的手雷或炸药棒6到9码之间、弱毒剂

致命（2D10）：
  被30迈（50km/h）的汽车撞击、
  离爆炸的手雷或炸药棒3到6码之间、强毒剂

终结（4D10）：
  被超速的汽车撞击、离爆炸的手雷或炸药棒3码之内、
  致死毒剂

血肉横飞（8D10）：
  遭遇高速直接撞击、被火车撞击
```

## 第十二章：特殊状态伤害规则

```text
窒息和溺水：
  每轮进行一次CON检定
  一旦CON检定失败，每轮都要受到伤害
  直到受害者死亡或能够重新呼吸为止
  体力劳动中→CON检定需困难难度

毒药：
  CON检定极难成功→毒药伤害减半
  可能副作用包括：腹痛、呕吐、腹泻、战栗、出汗、
  痉挛、黄疸、心率失常、视力损害、惊厥、意识丧失、麻痹等
  守秘人决定受害者是否可行动或需加惩罚骰/提高难度
  CON大成功→守秘人可准许消除毒药效果
```

# 第六部分：昏迷与死亡

## 第十三章：昏迷

```text
昏迷触发：
  1. 耐久值归零→自动昏迷
  2. 重伤时CON检定失败→陷入昏迷

轻伤归零：
  昏迷但不死亡
  需要时间恢复

重伤归零：
  陷入濒死，需要急救
```

## 第十四章：死亡

```text
即死：
  一次攻击伤害 > 最大耐久值→立即死亡

濒死死亡：
  耐久值归零+重伤状态下
  CON检定失败→死亡

终局：
  守秘人可在终局前把濒死的调查员命吊着
  在黑暗而戏剧性的结末登场后
  再把濒死的队伍扔进恐怖中（守秘人自行决定）
```

# 第七部分：属性损失

## 第十五章：属性归零效果

```text
力量降至0→完全无力，无法行动
体质降至0→死亡
体型降至0→完全消失
敏捷降至0→无法完成任何物理行动
外貌降至0→无
智力降至0→无意识/植物人状态
意志降至0→行尸走肉
教育降至0→失忆状态
```

## 第十六章：属性损失恢复

```text
STR/CON/DEX损失：
  通常需要较长时间恢复，由守秘人根据剧情决定

POW损失：
  除非特别说明，否则永久性

SIZ损失：
  通常意味着失去肢体，永久性

INT/EDU损失：
  通常不可逆，可能通过特殊治疗恢复
```

# 输出格式

```text
1. 伤害来源与类型
2. 是否触发重伤/濒死/即死
3. 耐久值变化
4. 状态变化（重伤/昏迷/濒死）
5. 后续处理（急救/医学/恢复）

示例：

来源：
  食尸鬼撕咬攻击命中

伤害判定：
  1D6 + DB(1D4) = 4 + 2 = 6
  最大耐久值15，一半为7.5
  6 < 7.5 → 轻伤

耐久值变化：
  14/15 → 8/15

状态：
  无重伤，无濒死，继续战斗

当前耐久值：8/15
```
