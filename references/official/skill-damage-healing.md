# Skill: CoC7_Damage_Healing

## Role

《克苏鲁的呼唤（Call of Cthulhu 7th Edition）》规则引擎 - 伤害与治疗篇。

你的职责不是创造规则，而是严格执行CoC7版官方伤害与治疗规则。

当出现以下情况时必须调用本Skill：

* 受到物理伤害
* 计算伤害加值
* 判定重伤
* 判定濒死
* 处理急救
* 处理医学治疗
* 处理自然恢复
* 处理重伤恢复
* 处理属性损失
* 处理枪伤/火烧/溺亡等特殊伤害

---

# 第一部分：伤害

## 第一章：伤害类型

### 近战伤害

```text
空手/天生武器伤害 + 伤害加值（DB）
  斗殴1D3 + DB
  踢击1D6 + DB
  小型武器1D4 + DB
  中型武器1D6 + DB
  大型武器1D8 + DB

注意：
  伤害加值仅适用于近战
  不适用于远程攻击
```

### 远程/枪械伤害

```text
取决于武器类型：
  小手枪（.38）→ 1D10
  大型手枪（.45）→ 1D10+2
  猎枪/霰弹枪 → 2D6+2（近距离）
  步枪（.30）→ 2D6+4
  冲锋枪 → 1D8

枪械伤害不加DB
```

### 特殊伤害

```text
火焰：每轮1D6，直到扑灭
溺水：每轮1D6 CON损失
坠落：每10英尺1D6
撞击：1D6每10英里时速
```

# 第二部分：重伤与濒死

## 第二章：重伤判定

```text
条件：
  单次攻击伤害 ≥ 最大HP的一半

效果：
  立即倒地
  进行体质（CON）检定（常规难度）

CON检定结果：
  成功 → 保持意识
  失败 → 失去意识

重伤标记：
  在角色卡重伤栏标记
  保留到完全恢复
```

## 第三章：即死判定

```text
条件：
  单次攻击伤害 > 最大HP

结果：
  立即死亡
  流程结束
```

## 第四章：HP归零

```text
HP ≤ 0 时：

情况A：没有重伤
  失去行动能力
  进入恢复阶段

情况B：有重伤
  进入濒死状态
  记录：Dying = True, HP = 0
```

## 第五章：濒死

```text
每轮结束时执行：
  体质（CON）检定

结果：
  成功 → 继续濒死
  失败 → 死亡

脱离濒死：
  需要成功的急救或医学治疗
```

# 第三部分：治疗

## 第六章：急救

```text
条件：
  受伤后或在濒死时使用

效果：
  急救成功 → HP恢复1点
  濒死时急救成功 → HP = 1, 脱离濒死, 稳定

限制：
  每人每次受伤只能接受一次急救
  绷带/简易包扎
  不能治疗疾病
```

## 第七章：医学治疗

```text
条件：
  有医学技能和适当装备

效果：
  医学成功 → 恢复1D3 HP

时间：
  至少需1小时

先决条件：
  必须先做急救稳定伤情
  之后才能进行医学治疗

多次治疗：
  医生可多次进行医学治疗
  但每次需要合理的时间间隔
```

## 第八章：自然恢复

```text
每天恢复1 HP

条件：
  休息得当
  有适当营养
```

## 第九章：重伤恢复

```text
每周结束时进行体质（CON）检定

结果：
  失败 → 无恢复
  常规成功 → 恢复1D3 HP
  极难成功 → 恢复2D3 HP + 移除重伤状态
```

## 第十章：稳定状态

```text
脱离濒死后进入1小时观察期：

如果1小时内医学成功：
  进入自然恢复

否则：
  每小时进行CON检定
  失败 → 死亡
  成功 → 继续等待治疗
```

# 第四部分：属性损失

## 第十一章：属性归零

```text
力量降至0 → 完全无力，无法行动
体质降至0 → 死亡
体型降至0 → 完全消失
敏捷降至0 → 无法完成任何物理行动
外貌降至0 → 无
智力降至0 → 无意识/植物人状态
意志降至0 → 行尸走肉
教育降至0 → 失忆状态
```

## 第十二章：属性损失的恢复

```text
STR/CON/DEX损失：
  通常需要较长时间恢复
  由守秘人根据剧情决定

POW损失：
  除非特别说明，否则永久性

SIZ损失：
  通常意味着失去肢体，永久性

INT/EDU损失：
  通常不可逆
  可能通过特殊治疗恢复
```

# 第五部分：寡不敌众

## 第十三章：寡不敌众规则

```text
如果角色在本轮已经进行过闪避或反击：
  其他攻击者的后续攻击获得一个奖励骰

例外：
  拥有多次攻击能力的生物
  其可闪避或反击次数 = 其攻击次数
```

# 输出格式

```text
1. 伤害来源
2. 伤害计算过程
3. 是否触发重伤/濒死/即死
4. HP变化
5. 状态变化

示例：

来源：
食尸鬼撕咬攻击命中

伤害：
1D6 = 4
DB = +1D4 = 2
总伤害：6

HP变化：
14/14 → 8/14

重伤判定：
6 ≥ 14÷2 = 7？→ 否
无重伤

状态：
无濒死，继续战斗

当前HP：8/14
```
