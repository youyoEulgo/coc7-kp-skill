# Skill: CoC7_Combat_System

## Role

《克苏鲁的呼唤（Call of Cthulhu 7th Edition）》规则引擎 - 战斗篇。

你的职责不是创造规则，而是严格执行CoC7版官方战斗规则。

当出现以下情况时必须调用本Skill：

* 建立行动顺序
* 处理突袭
* 声明战斗行动
* 执行对抗检定
* 处理闪避/反击/战技
* 处理体格差异
* 处理寡不敌众

**注意：** 伤害计算、重伤判定、濒死、急救、恢复等→ 调用 `skill-damage-healing.md`

---

# 核心原则

每次战斗遵循：

```text
建立行动顺序    ← 第一阶段
    ↓
突袭判定        ← 第二阶段
    ↓
按DEX依次行动   ← 第三~八阶段
    ↓
攻击与防御对抗
    ↓
计算伤害        ← 转 skill-damage-healing.md
重伤/濒死/恢复
```

---

# 第一阶段：建立行动顺序

```text
按DEX降序排序，DEX高者先行动

特殊情况：
  准备好的枪械 → DEX + 50

如果DEX持平：
  拥有较高战斗技能（Combat Skill）的角色先行动

输出行动顺序：
  1. [角色名] DEX
  2. [角色名] DEX
  3. ...
```

## 延迟行动（Delay）

```text
声明方式：
  角色可以声明将自己的行动次序延迟（Delay）
  延迟到其他角色行动完以后自己再行动

多个角色同时延迟：
  多个角色同时选择延迟到同一位置行动
  他们的行动次序也由敏捷值高到低排列

全部延迟：
  如果所有角色都向后延迟
  他们可能会完全跳过整一个战斗轮
  并在下一轮再按正常次序开始行动
```

---

# 第二阶段：突袭

判断目标是否意识到攻击。

```text
允许检定：侦查 / 聆听 / 心理学

目标察觉 → 正常进入战斗
目标未察觉 → 攻击自动成功 或 攻击获得奖励骰

然后进入正常战斗流程
```

---

# 第三阶段：行动声明

轮到角色行动时，必须声明以下之一：

```text
攻击 / 逃跑 / 战技 / 其他行动
```

如果目标遭到攻击，必须声明以下之一：

```text
闪避 / 反击 / 战技应对 / 不防御
```

---

# 第四阶段：对抗检定

计算双方成功等级，等级高者获胜。

成功等级顺序（高→低）：

```text
大成功 → 极难成功 → 困难成功 → 常规成功 → 失败 → 大失败
```

---

# 第五阶段：闪避

```text
防御方等级更高 → 攻击失效
攻击方等级更高 → 命中（计算伤害）
平局 → 防御方胜利

不造成反击伤害
```

---

# 第六阶段：反击

```text
防御方等级更高 → 反击成功，防御方造成伤害
攻击方等级更高 → 攻击命中（计算伤害）
平局 → 攻击方胜利
双方失败 → 无人受伤

注意：反击时不能使用极难成功额外效果
```

---

# 第七阶段：战技

```text
战技属于特殊反击，处理方式与反击一致

区别：造成效果，不造成伤害（除非特殊说明）
```

## 战技类型

### 压制（Grapple/Pin）

```text
目标：
  抓住对手，限制其行动

流程：
  战技检定对抗
  成功→目标被压制，无法自由行动
  被压制者每轮可通过战技检定尝试挣脱（承受惩罚骰）

挣脱失败：
  继续被压制
```

### 击倒（Knock Down）

```text
目标：
  将对手摔倒在地

流程：
  战技检定对抗
  成功→目标倒地
  倒地者承受战斗惩罚
```

### 绊摔（Trip）

```text
目标：
  用下肢绊倒对手

流程：
  战技检定对抗
  成功→目标倒地
```

### 缴械（Disarm）

```text
目标：
  打落对手手中的武器

流程：
  战技检定对抗
  成功→武器从对手手中脱落
```

### 推开（Shove）

```text
目标：
  将对手推开，拉开距离

流程：
  战技检定对抗
  成功→将对手推开
```

## 体格差异对战技的影响

```text
如果战技涉及体格对抗：
  BuildDifference = 目标体格 - 攻击者体格

  每差1级 → 攻击者获得1个惩罚骰
  BuildDifference ≥ 3 → 战技自动失败，无法发动
```

## 可选规则：击晕

```text
条件：
  使用钝击武器（拳击、棍棒、枪托等）
  发动一次战技攻击

效果：
  战技成功→目标被打晕
  只受到1点耐久值伤害

限制：
  只对有明显颅脑结构或可造成昏迷的弱点部位的生物有效
  （人类、深潜者、食尸鬼等可以；修格斯不行）
```

# 第十阶段：射击规则

射击检定不要求对抗检定，而是根据射程距离决定难度等级。

## 远程攻击难度等级

```text
基础射程内：普通难度等级
远射程（最大为基础距离的两倍）：困难难度等级
超射程（最大为基础距离的四倍）：极难难度等级
```

## 射击攻击与敏捷值次序

```text
扣动扳机所需的反应时间远少于挥舞刀剑。
只要角色已经准备好了射击武器，他就可以在以敏捷值
决定的行动轮行动次序时，视为拥有额外+50的敏捷值。
```

## 手枪连射

```text
手枪每轮可射击多次：
  每次额外射击给攻击检定增加一个惩罚骰

例如：
  手枪每轮可射击3次（1次基础+2次额外）
  第一次射击：正常检定
  第二次射击：1个惩罚骰
  第三次射击：2个惩罚骰
```

## 瞄准

```text
如果角色花一整轮时间瞄准目标：
  下一轮中轮到自己的回合时攻击获得一个奖励骰
```

## 寻找掩体

```text
目标可通过闪避检定寻找掩体：
  成功→射击攻击者承受一个惩罚骰
  代价→目标丧失下一次攻击的机会
```

## 掩蔽和掩护

```text
掩蔽物可为目标提供护甲值：
  例如：砖墙提供10点护甲值
  攻击需要穿透掩蔽物才能伤害到目标
```

---

# 伤害/重伤/濒死/恢复

```text
如果角色在本轮已经进行过闪避或反击：
  其他攻击者的后续攻击获得一个奖励骰

例外：
  拥有多次攻击能力的生物
  其可闪避或反击次数 = 其攻击次数
```

---

# 伤害/重伤/濒死/恢复

→ 转入 **`skill-damage-healing.md`**

```text
命中后：
  计算伤害
  HP变化
  重伤判定（Damage ≥ MaxHP÷2）
  即死判定（Damage > MaxHP）
  HP归零判定
  濒死处理
  急救/医学/自然恢复
  重伤恢复
```

---

# 输出格式

每次战斗结算必须输出：

```text
1. 行动顺序
2. 检定结果
3. 成功等级
4. 伤害结果（→ skill-damage-healing.md 详细处理）
5. HP变化
6. 状态变化
7. 当前状态

示例：
行动：张三攻击食尸鬼
检定：张三斗殴 42/65（成功）
      食尸鬼闪避 71/40（失败）
结果：攻击命中
伤害：1D3+1 = 3
HP：11 → 8
状态：无重伤，无濒死
当前HP：8/11
```
