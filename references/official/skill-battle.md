# Skill: CoC7_Combat_System

## Role

《克苏鲁的呼唤（Call of Cthulhu 7th Edition）》规则引擎 - 战斗篇。

你的职责不是创造规则，而是严格执行CoC7版官方战斗规则。

当出现以下情况时必须调用本Skill：

* 建立行动顺序
* 处理突袭
* 声明战斗行动
* 执行对抗检定
* 处理闪避/反击/战技
* 处理体格差异
* 处理寡不敌众

**注意：** 伤害计算、重伤判定、濒死、急救、恢复等→ 调用 `skill-damage-healing.md`

---

# 核心原则

每次战斗遵循：

```text
建立行动顺序    ← 第一阶段
    ↓
突袭判定        ← 第二阶段
    ↓
按DEX依次行动   ← 第三~八阶段
    ↓
攻击与防御对抗
    ↓
计算伤害        ← 转 skill-damage-healing.md
重伤/濒死/恢复
```

---

# 第一阶段：建立行动顺序

```text
按DEX降序排序，DEX高者先行动

特殊情况：
  准备好的枪械 → DEX + 50

输出行动顺序：
  1. [角色名] DEX
  2. [角色名] DEX
  3. ...
```

---

# 第二阶段：突袭

判断目标是否意识到攻击。

```text
允许检定：侦查 / 聆听 / 心理学

目标察觉 → 正常进入战斗
目标未察觉 → 攻击自动成功 或 攻击获得奖励骰

然后进入正常战斗流程
```

---

# 第三阶段：行动声明

轮到角色行动时，必须声明以下之一：

```text
攻击 / 逃跑 / 战技 / 其他行动
```

如果目标遭到攻击，必须声明以下之一：

```text
闪避 / 反击 / 战技应对 / 不防御
```

---

# 第四阶段：对抗检定

计算双方成功等级，等级高者获胜。

成功等级顺序（高→低）：

```text
大成功 → 极难成功 → 困难成功 → 常规成功 → 失败 → 大失败
```

---

# 第五阶段：闪避

```text
防御方等级更高 → 攻击失效
攻击方等级更高 → 命中（计算伤害）
平局 → 防御方胜利

不造成反击伤害
```

---

# 第六阶段：反击

```text
防御方等级更高 → 反击成功，防御方造成伤害
攻击方等级更高 → 攻击命中（计算伤害）
平局 → 攻击方胜利
双方失败 → 无人受伤

注意：反击时不能使用极难成功额外效果
```

---

# 第七阶段：战技

```text
战技属于特殊反击，处理方式与反击一致

区别：造成效果，不造成伤害

例如：缴械 / 绊摔 / 压制 / 推开
```

---

# 第八阶段：体格差异

若战技涉及体格对抗：

```text
BuildDifference = 目标体格 - 攻击者体格

每差1级 → 获得1个惩罚骰
BuildDifference ≥ 3 → 战技自动失败，无法发动
```

---

# 第九阶段：寡不敌众

```text
如果角色在本轮已经进行过闪避或反击：
  其他攻击者的后续攻击获得一个奖励骰

例外：
  拥有多次攻击能力的生物
  其可闪避或反击次数 = 其攻击次数
```

---

# 伤害/重伤/濒死/恢复

→ 转入 **`skill-damage-healing.md`**

```text
命中后：
  计算伤害
  HP变化
  重伤判定（Damage ≥ MaxHP÷2）
  即死判定（Damage > MaxHP）
  HP归零判定
  濒死处理
  急救/医学/自然恢复
  重伤恢复
```

---

# 输出格式

每次战斗结算必须输出：

```text
1. 行动顺序
2. 检定结果
3. 成功等级
4. 伤害结果（→ skill-damage-healing.md 详细处理）
5. HP变化
6. 状态变化
7. 当前状态

示例：
行动：张三攻击食尸鬼
检定：张三斗殴 42/65（成功）
      食尸鬼闪避 71/40（失败）
结果：攻击命中
伤害：1D3+1 = 3
HP：11 → 8
状态：无重伤，无濒死
当前HP：8/11
```
