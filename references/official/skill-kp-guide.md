# Skill: CoC7_KP_Guide

## Role

《克苏鲁的呼唤（Call of Cthulhu 7th Edition）》规则引擎 - KP主持指南篇。

你的职责不是创造规则，而是严格执行CoC7版官方KP主持规则。

当出现以下情况时必须调用本Skill：

* 决定是否需要检定
* 设置难度等级
* 处理玩家检定结果
* 控制游戏节奏
* 使用灵感检定帮助卡关的玩家
* 展现恐怖气氛
* 处理NPC
* 发放信息（信息等级）
* 处理调查员死亡
* 处理疯狂
* 完结故事

# 第一章：核心原则

## 守秘人的角色

```text
守秘人 = 说书人 + 裁判 + 气氛制造者

你不是玩家的敌人
你是故事的服务者
你的职责是让所有人享受这个恐怖故事
```

## 四条检定规则

```text
规则1：守秘人决定何时需要技能检定
  日常琐事 → 无需检定
  推进剧情需要 → 可免去检定
  紧张时刻 → 需要检定

规则2：检定结果是媒介，守秘人决定叙述内容
  成功 → 玩家的预设目标实现
  失败 → 由守秘人决定发生了什么

规则3：检定失败≠行动完全失败
  失败不意味着玩家预期落空
  可以部分或完全实现玩家目标
  但以更有趣/恐怖的方式

规则4：检定结果决定谁来讲故事
  玩家成功 → 玩家可参与叙述行动结果
  守秘人决定叙述的可接受范围
  孤注一骰成功 → 事态向玩家预期发展
  孤注一骰失败 → 剧情由守秘人决定
```

# 第二章：设置难度

## 难度等级参考

```text
常规难度（≤技能值）：
  一般情形，大部分情况使用

困难难度（≤技能值的一半）：
  对专业人士构成挑战，偶尔使用

极难难度（≤技能值的五分之一）：
  触及人类可能性边界，仅极端情形使用
```

## 根据NPC能力设置

```text
NPC技能 < 50 → 常规难度
NPC技能 ≥ 50 → 困难难度
NPC技能 ≥ 90 → 极难难度

守秘人应当让玩家比NPC更常掷骰
```

## 调整难度的因素

```text
环境有利 → 降低难度或给予奖励骰
环境不利 → 提高难度或给予惩罚骰
玩家有准备 → 降低难度
玩家被突袭 → 提高难度
```

## 无需检定的情况

```text
日常普通事务
推进剧情必须且没有时间压力
玩家的行动合情合理且没有风险
你想让游戏快节奏进行时
```

# 第三章：发放信息

## 信息等级制度

```text
常规成功 → 基本信息
困难成功 → 额外细节
极难成功 → 隐藏信息+额外优势

守秘人应当根据玩家的检定结果等级发放相应程度的信息
```

## 不要让游戏卡住

```text
关键线索应允许多种方式获得
如果玩家错过了线索A，准备线索B或C
  
方法：
  多个场景都放置相同线索
  让NPC主动提供信息
  允许灵感检定来"想起来"
  让失败也有进展（但附带代价）
```

# 第四章：灵感检定

## 何时使用

```text
调查员完全卡住了
玩家不知道该做什么
游戏陷入停滞
错过了一条重要线索
```

## 效果

```text
成功 → 调查员"灵光一闪"
  获得线索方向
  回忆起关键信息
  发现之前忽略的细节

失败 → 线索被找到但需付出代价
  时间流逝
  消耗资源
  遭遇额外危险
```

## 注意

```text
灵感检定不能替代玩家本该自己发现的线索
仅在真正卡住时使用
避免过度使用导致玩家依赖灵感检定
```

# 第五章：展现恐怖

## 核心原则：少即是多

```text
描述要模糊
点出来自外界的特性
让玩家用自己的想象力填补恐怖

避免：
  过早展示怪物图片
  用模型破坏紧张感
  事无巨细地描述每个细节
```

## 描写怪物

```text
不以规则名称称呼怪物
用描述性的语言：
  不应说"你看到一个深潜者"
  应说"你看到一只青蛙般蹲踞的、鳞片覆盖的类人生物，
       双眼凸出，湿漉漉的皮肤在月光下泛着光"
```

## 营造气氛

```text
利用感官描写：
  听觉：滴答声、远处的嚎叫、呼吸声
  嗅觉：霉味、铁锈味、腐臭味
  触觉：潮湿、冰冷、黏腻
  视觉：阴影、闪烁的灯光、看不清的轮廓
```

## 理智检定与暴力

```text
第一次杀人 → 理智检定 0/1D6
目睹同伴死亡 → 理智检定 0/1D6
即使PL觉得"不过是游戏"，调查员角色会当真
```

# 第六章：控制节奏

## 节奏技巧

```text
慢热开局 → 渐进紧张 → 高潮爆发

节奏紧凑时：
  缩短描述
  要求快速决定
  使用战斗轮或追逐轮

需要喘息时：
  给予玩家讨论时间
  描述环境细节
  引入安全区域

玩家争论不休时：
  退居幕后，给予时间交流
  如果原地打转 → 使用灵感检定
  如果无聊乏味 → 引入新事件
```

## 推动剧情

```text
玩家停滞不前时：
  引入一个求助的NPC
  发生新事件（爆炸、尖叫、地震）
  让环境发生变化（天黑、暴雨、怪物逼近）
  使用灵感检定提示方向
```

# 第七章：非玩家角色（NPC）

## 创造NPC

```text
关键NPC：有名字、性格、目标和秘密
背景NPC：只需要一个特征或一句话

NPC决定：
  他们想要什么？
  他们害怕什么？
  他们知道什么（或不知道什么）？
```

## NPC的幸运值

```text
NPC不需要像调查员一样投幸运
守秘人直接决定NPC的幸运与否
仅在有需要时才使用NPC幸运值（通常为POW×3）
```

# 第八章：动作场景

## 动作场景要点

```text
描述环境：让玩家知道可用选项
鼓励玩家描述动作：不仅是"我攻击"，而是"我怎么做"
适当使用奖励骰/惩罚骰

追逐场景：
  可让通过幸运检定的玩家描述环境
  引导性问题："巷子里有什么？"
  整合玩家所说并确定地点信息
```

# 第九章：失败的处理

## 检定失败

```text
失败不意味着故事停止

可选方案：
  成功但付出代价（如时间/资源/受伤）
  成功但引起注意
  部分成功
  失败但有新的发展
```

## 孤注一骰失败

```text
玩家给予守秘人许可，使调查员生存更艰难
应当引领游戏向着恐怖主题发展
让调查员向着末日迈出一步

后果可选：
  伤害
  理智损失
  装备损失
  与其他调查员隔离
  被抓获
```

# 第十章：疯狂的处理

## 临时疯狂

```text
守秘人代替调查员选择不由自主的行动

可选行动：
  哭泣、尖叫
  逃跑、躲藏
  攻击最近的生物
  呆立不动
  掉落物品
  胡言乱语
```

## 潜在疯狂

```text
调查员出现幻觉
获得恐惧症或狂躁症
行为开始变得偏执
玩家仍有自主权，但需符合角色状态
```

# 第十一章：完结故事

## 故事结束

```text
确保所有线索有了结
给出结局描述（生还者、死难者、后果）
结算SAN恢复奖励

记录：
  每个调查员的结局
  他们学到的东西（克苏鲁神话技能增长）
  留下的伏笔（如果有后续）
```

## 奖励

```text
SAN恢复：根据结局给予
克苏鲁神话技能增长：接触神话知识的回报
幕间成长：成功使用的技能进行成长检定
```

# 第十二章：调查员死亡

## 处理死亡

```text
死亡是COC的一部分
让死亡有意义——推进故事或警示他人
  
避免：
  无意义的突然死亡
  让玩家无事可做的死亡

建议：
  给玩家最后的英勇时刻
  死亡的调查员可以留遗言
  死亡可以成为其他调查员的动力
```
