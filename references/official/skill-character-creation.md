# Skill: CoC7_Character_Creation

## Role

《克苏鲁的呼唤（Call of Cthulhu 7th Edition）》规则引擎 - 创建调查员篇。

你的职责不是创造规则，而是严格执行CoC7版官方角色创建规则。

当出现以下情况时必须调用本Skill：

* 创建新调查员
* 决定属性值
* 选择职业
* 分配技能点
* 决定年龄/老化调整
* 计算伤害加值/体格
* 计算生命值
* 计算幸运值
* 决定装备
* 撰写背景

# 第一章：决定属性

## 8项基础属性

```text
力量（STR）：3D6 × 5
  肌肉能力，决定近战伤害

体质（CON）：3D6 × 5
  健康、生气和活力，决定生命值

体型（SIZ）：(2D6+6) × 5
  身高体重，决定生命值和伤害加值

敏捷（DEX）：3D6 × 5
  速度、柔韧性，决定行动顺序

外貌（APP）：3D6 × 5
  肉体吸引力和人格魅力，用于社交

智力（INT）：(2D6+6) × 5
  学习力、理解力、分析力
  决定兴趣技能点数量

意志（POW）：3D6 × 5
  心意力量，决定理智值和魔法值

教育（EDU）：(2D6+6) × 5
  正规知识量，决定职业技能点数量
```

## 派生数值

```text
生命值（HP） =（体质 + 体型）÷ 10
  省略小数

理智值（SAN）= 意志值（POW）
  初始值，上限为 99 - 克苏鲁神话技能

魔法值（MP）= 意志值（POW）÷ 5
  用于施法

幸运值（LUCK）= 3D6 × 5
  创建时可骰2次取较好的一次

移动力（MOV）：
  力量 < 体型 且 敏捷 < 体型 → 7
  力量 ≥ 体型 或 敏捷 ≥ 体型 → 8
  两者都 ≥ 体型 → 9
  两者都 < 体型 → 6
```

## 伤害加值（DB）和体格

```text
根据 力量 + 体型 合计值查表：

  STR+SIZ ≤ 64  → DB: -1D4,  体格: -2
  STR+SIZ 65-84 → DB: 无,     体格: 0
  STR+SIZ 85-124 → DB: +1D4,  体格: 1
  STR+SIZ 125-164 → DB: +1D6,  体格: 2
  STR+SIZ 165-204 → DB: +2D6,  体格: 3
  此后每超过80点：+1D6 DB, +1 体格

注意：
  伤害加值适用于近战
  不适用于远程攻击
```

## 选定职业

```text
职业反映调查员的生活方式

职业提供：
  本职技能列表（8个技能）
  信用评级范围和起始点
  职业技能点计算公式
```

```text
医生：急救、拉丁文、医学、心理学、科学(生物学)、科学(药学)、选二
```

## 信用评级范围

```text
每个职业有特定的信用评级范围和起始点
玩家在范围内分配信用评级
部分职业技能点可分配给信用评级
```

# 第三章：分配技能点

## 技能点来源

```text
职业技能点 = 教育（EDU）× 某倍数（因职业而异，通常是×2或×4）
兴趣技能点 = 智力（INT）× 2
```

## 分配规则

```text
职业技能点只能分配给本职技能（及信用评级）
兴趣技能点可分配给任何技能

初始值：所有技能都有基础值（如斗殴25%、闪避DEX/2等）
技能点在基础值上增加

信用评级：
  初始为0
  可用本职技能点分配
  不能超过职业的范围上限
```

## 快速开桌方案（可选）

```text
1. 将40、50、50、50、60、60、70、80分配在属性上
2. 决定年龄，进行教育调整
3. 算出伤害加值和体格
4. 算出生命值和幸运
5. 选择职业和8个职业技能
6. 将技能分配：1项70%、2项60%、3项50%、3项40%
7. 信用评级选合适点数（如果职业最高<40%，多余点数分到别处）
8. 选4个非本职技能各+20%
9. 直接开始玩，边玩边写半值和五分之一值
```

# 第四章：年龄调整

```text
15-19岁：
  力量和体型合计减5
  教育减5
  幸运可骰2次取较好

20-39岁：
  对教育进行1次增强检定

40-49岁：
  对教育进行2次增强检定
  对力量、体质、敏捷各进行1次老化减值检定

50-59岁：
  对教育进行3次增强检定
  对力量、体质、敏捷各进行2次老化减值检定

60-69岁：
  对教育进行4次增强检定
  对力量、体质、敏捷各进行3次老化减值检定

70-79岁：
  对教育进行4次增强检定
  对力量、体质、敏捷各进行4次老化减值检定

80-89岁：
  对教育进行4次增强检定
  对力量、体质、敏捷各进行4次或更多老化减值检定
```

## 教育增强检定

```text
掷1d100
若结果 > 当前教育值 → 骰1d10，加到教育值上
若结果 ≤ 当前教育值 → 不变
```

## 老化减值检定

```text
掷1d100
若结果 > 当前属性值 → 属性减1d10（力量/体质/敏捷）
若结果 ≤ 当前属性值 → 不变
```

# 第七章：可选创建方案

## 方案一：重复开始

```text
若对骰出的属性不满意
可推翻所有出目重新开始
三个或更多属性低于50时，守秘人通常会允许重骰
```

## 方案二：修改低骰子

```text
若有过多小骰子（三个或更多骰子在10以下）
可额外骰1个1d6，将出目分配在这些小骰子上
以上操作均在×5之前进行
```

## 方案三：自由分配

```text
骰5次3d6，3次2d6+6
然后将出目自由分配到8个属性上
```

## 方案四：购点制

```text
将460点分配在8个属性上（限制：15-90）
智力和体型不能低于40
没有属性低于15
```

## 方案五：快速开桌

```text
见第三章"快速开桌方案"
```
