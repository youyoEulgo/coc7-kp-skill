# Skill: CoC7_Skills

## Role

《克苏鲁的呼唤（Call of Cthulhu 7th Edition）》规则引擎 - 技能列表篇。

你的职责不是创造规则，而是严格执行CoC7版官方技能定义。

当出现以下情况时必须调用本Skill：

* PL声明行动后需要选择最适合的技能
* 查询技能基础值
* 查询技能用法和对抗技能
* 查询孤注一骰失败后果
* 分配技能点

---

# 第一章：技能概览

## 技能值格式

```text
技能名（基础值%）
  用法描述
  对抗技能/难度等级
  孤注一骰失败范例
```

## 常规技能 vs 非常规技能

```text
常规技能：写在标准角色卡上的技能
非常规技能（标注"非常规"）：未写在标准角色卡上的技能，需特殊理由才能学习
```

## 技能专攻

```text
某些技能被分成多个独立技能（如格斗分为斗殴、剑、矛等）
选择时需指定专攻方向
```

# 第二章：按类别技能列表

## 社交类

```text
魅惑（15%）
  通过肉体魅力、诱惑、奉承等影响他人
  对抗：目标心理学或魅惑
  孤注一骰失败：目标产生敌意；声誉受损；性病

话术（05%）
  通过花言巧语、诡辩误导他人
  对抗：目标心理学或话术
  孤注一骰失败：目标看穿意图并产生敌意

恐吓（15%）
  通过暴力威胁、胁迫恐吓他人
  对抗：目标心理学或恐吓
  孤注一骰失败：目标报警；目标暴力反抗

说服（10%）
  通过逻辑论证、理性辩论使他人信服
  对抗：目标心理学或说服
  孤注一骰失败：目标更加固执己见
```

## 知识类

```text
会计（05%）
  理解会计工作流程和财务状况
  发现假账、挪用资金、行贿款项等
  对抗：隐藏方的会计技能
  孤注一骰失败：被指控伪造；引发审计

人类学（01%）
  通过观察辨认和理解文化方式
  预测文化行为和信仰（需观察一段时间）
  对抗：无

考古学（01%）
  理解历史遗迹和古代文明
  挖掘和解读古代文物
  对抗：无
  孤注一骰失败：误判年代；破坏遗迹

历史（05%）
  记忆和回忆历史事件、人物、背景
  对抗：无
  孤注一骰失败：记错信息；混淆时代

图书馆使用（20%）
  查找信息、检索档案、利用图书馆资源
  对抗：无（若有隐藏信息，守秘人决定难度）
  孤注一骰失败：引起注意；被禁止进入

神秘学（05%）
  了解超自然传说、秘教符号、巫术传统
  注意：不等于克苏鲁神话知识
  对抗：无

心理学（10%）
  洞察他人真实意图和情绪状态
  对抗：目标的伪装技能（魅惑/话术/恐吓/说服）
  孤注一骰失败：严重误判；产生偏见
```

## 医疗类

```text
急救（30%）
  进行紧急医疗处理、稳定伤情
  恢复1 HP（重伤需先止血）
  对抗：无
  孤注一骰失败：造成额外伤害（1D3）

医学（01%）
  诊断和治疗疾病、创伤、中毒
  恢复1D3 HP（需至少1小时和适当装备）
  对抗：疾病/毒素强度
  孤注一骰失败：误诊；治疗失败导致情况恶化

精神分析（01%）
  治疗精神障碍、安抚疯狂发作
  帮助恢复SAN值
  需多次治疗和较长时间
  对抗：无
  孤注一骰失败：患者状况恶化
```

## 侦查与感知类

```text
侦查（25%）
  发现细节、察觉异常、注意到隐藏的事物
  对抗：目标的潜行或隐藏技巧
  孤注一骰失败：错过重要线索；误报警

聆听（20%）
  听到远处或细微的声音、 eavesdropping
  对抗：发出声音者的潜行
  孤注一骰失败：听错方向；被认为是偷窥狂

读唇（01%）
  通过观察嘴唇运动理解对话内容
  需要能看到对方嘴唇
  孤注一骰失败：读错关键信息

追踪（10%）
  通过足迹、痕迹追踪人或动物
  对抗：被追踪者的潜行或相关技巧
  孤注一骰失败：跟丢；被反追踪
```

# 第三章：技能使用要点

## 对抗技能速查

```text
社交技能 → 对抗目标心理学或对应的社交技能
潜行 → 对抗观察者的侦查或聆听
妙手/乔装 → 对抗观察者的侦查
锁匠 → 对抗锁具质量决定的难度
急救/医学 → 对抗伤势/疾病严重度
```

## 常用技能初始值速查

## 技能成长

```text
游戏中成功使用技能 → 在角色卡上做标记
幕间成长阶段 → 每个标记技能可进行成长检定
骰1d100 > 当前技能值 → 骰1d10加到技能上
克苏鲁神话和信用评级永远不会获得技能成长标记
```
