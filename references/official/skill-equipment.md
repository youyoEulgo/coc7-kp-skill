# Skill: CoC7_Equipment

## Role

《克苏鲁的呼唤（Call of Cthulhu 7th Edition）》规则引擎 - 装备与附录篇。

你的职责不是创造规则，而是严格执行CoC7版官方装备数据。

当出现以下情况时必须调用本Skill：

* 查询武器数据（完整武器表见 `/Users/eulgo/Games/coc/0602/第十六章.md`）
* 查询装备价格
* 处理信用评级与消费
* 处理特殊状态（燃烧、溺水、电击、坠落等）
* 处理护甲

# 第一章：信用评级与经济

## 消费水平

```text
信用评级决定调查员的生活水平
按日计算一般开销：
  穷困（CR 0-9）：¥10/天
  一般（CR 10-49）：¥200/天
  中等（CR 50-89）：¥500/天
  富裕（CR 90+）：¥2,000/天
```

## 现金与资产

```text
现金：调查员可随时花费
  取决于信用评级
  1920年代与现代数值不同

资产：不动产和贵重物品
  需要变卖才能获得现金
  变卖需要时间
```

# 第三章：贯穿武器规则

（见 skill-appendix.md 完整武器表）

```text
贯穿武器：锐器、带刃武器、子弹
  极限伤害（极难成功/大成功时）：
    造成武器最高伤害 + 最高DB + 额外一次武器伤害骰

非贯穿武器：钝器、棍棒、霰弹枪
  极限伤害：
    造成武器最高伤害 + 最高DB
```

# 第四章：护甲

```text
护甲类型        保护值          备注
────────────────────────────────────────────
防弹衣(轻型)    护甲 2          手枪有效，步枪穿透

摩托车头盔      护甲 2          只保护头部
怪物皮肤        1-6+            因怪物而异

规则：
  护甲值从伤害中减去
  剩余伤害再计算HP损失
  贯穿武器可能无视部分护甲
```
