# 附录

## 附录Ⅰ：术语表

COC 中使用的关键名词索引。

| 术语 | 说明 |
|------|------|
| 1D100 | 见百分骰 |
| 1D4, 1D6; 1D8; 1D10等 | 标识骰子的数量及面数 |
| 冒险(Adventure) | 见模组(Scenario) |
| APP | 外貌(Appearance)，属性的一种 |
| 护甲(Armor) | 减少所受的伤害。从伤害中减去护甲值，结果才是实际损失的HP |
| 资产(Assets) | 来自信用评级(Credit Rating)。以资产存在的财富在变现后才能被花费 |
| 背景故事(Backstory) | 用于确定调查员的特征 |
| 基础技能等级(Base Chance) | 未经训练的调查员成功使用技能的几率 |
| 相信者(Believer) | 调查员可能间接认识到克苏鲁神话而并不真的相信神话 |
| 奖励骰(Bonus Die) | 进行技能或属性检定时，投百分骰和额外一颗十位骰，应用出目更好(较低)的十位骰的结果 |
| 疯狂发作(Bout of Madness) | 疯狂发生时，调查员所经历的第一个疯狂阶段 |
| 体格(Build) | 衡量物理尺寸、力气和耐久性的单位 |
| 战役(Campaign) | 同一组调查员参加的一系列相连模组 |
| 属性(Characteristic) | 力量(STR)、体质(CON)、体型(SIZ)、智力(INT)、敏捷(DEX)、外貌(APP)和教育(EDU)等 |
| 追逐(Chase) | 进行追击或逃离时改变位置的一系列行动 |
| 现金(Cash) | 来自信用评级(Credit Rating)，调查员可以随时花费 |
| 成长标记(Check/Tick) | 成功使用技能后在技能旁做标记，幕间成长时进行成长检定 |
| 战斗轮/追逐轮 | 弹性游戏时间单位，角色的行动顺序由DEX排序 |
| 组合技能检定 | 将一次掷骰结果与多个技能相比较 |
| CON | 体质(Constitution)，属性的一种 |
| 结果/后果(Consequence) | 孤注一骰失败所产生的负面后果 |
| 信用评级(Credit Rating) | 决定角色可用的现金及资产的数量 |
| 大成功(Critical) | 1D100掷出"01"永远成功，且会造成有益结果 |
| 克苏鲁(Cthulhu) | 洛氏神话中知名度最高的邪神 |
| 克苏鲁神话技能 | 关于宇宙诸神、神话存在、怪物和恶魔的知识 |
| 伤害(Damage) | 受到攻击和意外损伤，从生命值中减去伤害值 |
| 伤害加值(DB) | 由STR与SIZ的加值衍生 |
| 死亡(Death) | HP归零且急救或医学失败且未通过CON检定的重伤角色会死亡 |
| 深层魔法 | 比通常版本更有效的法术变体 |
| 幻觉(Delusion) | 疯狂中产生的幻觉，玩家可进行现实认知检定看破 |
| 幕间成长 | 发生在游戏结束或模组结束时，玩家为调查员做成长检定 |
| DEX | 敏捷(Dexterity)，属性的一种 |
| 敏捷排序 | 战斗和追逐中，角色的行动顺序按照DEX数值从高到低排序 |
| 骰子，掷骰/投骰 | 表示需要掷骰来确定游戏中发生的结果 |
| 难度等级 | 常规难度、困难难度和极难难度三种 |
| 寻找掩体 | 射击目标察觉到射击者而寻找掩体，进行闪避检定 |
| 闪避(Dodge) | 用来回避近战及枪械攻击的技能 |
| 濒死(Dying) | 生命值归零且处于重伤状态的角色即会濒死 |
| EDU | 教育(Education)，属性的一种 |
| 极难成功 | 检定结果小于等于技能或属性值的五分之一 |
| 五分之一 | 用于极难难度 |
| 战技 | 使用格斗技能而并非简单造成伤害的战术动作 |
| 急救(First Aid) | 可以回复1点生命值，或为濒死角色稳定伤势 |
| 揭示预兆 | 孤注一骰前，守秘人可揭示其失败后可能发生的后果 |
| 精读 | 对神话典籍的系统性学习 |
| 大失败 | 被检定值小于50时掷出96-100，或被检定值≥50时掷出100 |
| 目标(Goal) | 玩家进行检定所想要实现的效果 |
| 一半 | 用于困难难度 |
| 展示材料 | 守秘人交给玩家的文件或其它东西，通常是一些线索 |
| 近战 | 空手搏斗或近战武器 |
| 困难成功 | 检定结果小于等于技能或属性值一半的情况 |
| 险境 | 追逐中的位置，可能会使角色受伤或减缓速度 |
| 治疗 | 受伤角色每天自动恢复1点生命值(非重伤)，重伤需检定 |
| 生命值/耐久值(HP) | 等于CON与SIZ之和除以10向下取整 |
| 人类极限 | 调查员无法对抗超过自身100点或更高的属性 |
| 灵感检定 | 玩家发现游戏陷入僵局时，守秘人会将他们引回正轨 |
| 贯穿 | 攻击检定中取得极难成功，造成更大伤害 |
| 不定性疯狂 | 一天内失去1/5或更多当前理智时发生 |
| 永久性疯狂 | 当前理智归零，调查员彻底疯了 |
| 临时性疯狂 | 单次理智检定中失去5点或更多理智时发生 |
| INT | 智力(Intelligence)，属性的一种 |
| 泛读 | 对神话典籍的粗读 |
| 调查员 | COC中的玩家角色(PC) |
| 调查员幕间成长 | 游戏结束或模组结束时，玩家为调查员做成长检定 |
| 守秘人(Keeper) | COC中的游戏主持人 |
| 知识/教育检定 | 一次教育检定 |
| 成功等级 | 失败、常规成功、困难成功与极难成功 |
| 幸运(Luck) | 体现角色在其无法掌控的事件上的运气 |
| 幸运检定 | 用来决定调查员在外部情况下的命运 |
| 疯狂(Madness) | 见疯狂发作 |
| 魔法值(MP) | 由POW属性衍生，用来施法 |
| 重伤 | 单次攻击造成的伤害≥角色最大生命值的一半 |
| 最大理智值 | 等于99减克苏鲁神话技能 |
| 医学(Medicine) | 为受伤或患病的角色回复1D3点HP |
| 移动速度等级(MOV) | 角色在一轮中可以移动的距离（米或码） |
| 神话等级 | 衡量神话典籍中记载的克苏鲁神话知识深度 |
| NPC | 由守秘人扮演的非玩家角色 |
| 隐秘线索 | 玩家未能通过洞察检定时，守秘人可决定不提供的线索 |
| 显明线索 | 守秘人认为是必要的线索，可以轻易交给玩家 |
| 职业(Occupation) | 调查员的生活来源 |
| 对抗检定 | 双方各自进行检定，对比成功等级 |
| 可选规则 | 作为标准规则的补充或替代，由守秘人决定是否使用 |
| 寡不敌众 | 角色进行过反击或闪避后，接下来所有攻击都有一个奖励骰 |
| 惩罚骰 | 进行技能或属性检定时，应用出目更差(较高)的十位骰的结果 |
| 百分骰 | 游戏中的大部分检定都需要用到1D100 |
| 洞察检定 | 包括侦查、心理学和聆听技能，有时也包括追踪 |
| 兴趣技能点 | 创建调查员时，玩家可向任何技能投入INT×2点技能点 |
| 抵近射击 | 目标在射击者1/5DEX范围内时，射击者得到奖励骰 |
| POW | 意志(Power)，属性的一种 |
| 孤注一骰 | 提供第二次技能检定的机会，失败会带来糟糕的后果 |
| 现实认知检定 | 玩家进行理智检定来尝试看穿幻觉 |
| 轻伤 | 所有单次受到的伤害都<最大生命值的一半 |
| 常规成功 | 检定结果≤技能或属性值 |
| 理智(Sanity) | 调查员的理智状态 |
| 理智损失 | 因可怕经历而损失的理智值 |
| 理智点数(SAN) | 起始值等于角色的POW |
| 理智检定 | 投1D100，≤当前理智则成功 |
| 模组(Scenario) | 专为角色扮演设计的一系列故事 |
| SIZ | 体形(Size)，属性的一种 |
| 技能(Skill) | 一项明确的知识、技术或身体能力 |
| 技能检定 | 投1D100 |
| STR | 力量(Strength)，属性的一种 |
| 突袭 | 出人意料的攻击 |
| 古籍，神话典籍 | 记载着克苏鲁神话知识的书 |
| 昏迷 | 受到重伤且CON检定失败时可能陷入昏迷 |

### 属性检定转化

| 旧版要求 | 新版处理 |
|----------|----------|
| 1倍属性（如1倍POW、1倍STR） | 极难难度（属性的1/5） |
| 2～3倍属性 | 困难难度（属性的一半） |
| 4～6倍属性 | 普通难度（正常属性值） |
| 7～8倍属性 | 普通难度加一个奖励骰 |

## 游戏系统摘要

### 技能检定

- 在任何掷骰之前先陈述目标
- 为掷骰确定难度等级
- **大成功**：掷出01
- **大失败**：掷出100总会造成大失败；若成功范围低于50，则96-100造成大失败

**难度等级：**
- **常规难度**：对手技能/属性<50，掷出≤技能或属性则成功
- **困难难度**：对手技能/属性≥50，掷出≤技能或属性的一半成功
- **极难难度**：对手技能/属性≥90，掷出≤技能或属性的五分之一成功

### 对抗检定

| 等级顺序 | 说明 |
|----------|------|
| 大成功 > 极难成功 > 困难成功 > 常规成功 > 失败/大失败 |
| 平手 | 技能(或属性)更高的一方获胜 |
| 仍平手 | 达成僵局或者双方都重骰 |

对抗检定不能孤注一骰。

### 奖励骰与惩罚骰

- **奖励骰**：额外掷一个十位骰，采用较好的（较小的）结果
- **惩罚骰**：额外掷一个十位骰，采用较差的（较大的）结果


## 近战规则摘要

1. **确定攻击次序**：按DEX从高到低排序
2. **进行一个行动**：攻击、闪避、反击、逃跑、释放法术等
3. **被攻击者可以选择**：反击、闪避攻击或使用战技回击
4. **双方进行技能检定**
5. **确定攻击结果**

### 战技摘要

- 比较战技发起方和目标的体格(Build)
- 如果发起方Build较小，每点Build带来1个惩罚骰
- 差值为3或更高则不能发动战技
- 进行攻击检定，对手选择闪避或反击

## 追逐规则摘要

### 建立追逐

1. 所有参与者进行**速度骰**（体质或汽车驾驶）
2. 调整MOV：极难成功+1，失败-1
3. 逃离者速度高于所有追逐者则成功逃离
4. 切入正题：放置追逐者、逃离者、险境和障碍
5. 分配行动点：默认1点，与最慢参与者的每点MOV差值+1
6. 按DEX顺序确定行动顺序
