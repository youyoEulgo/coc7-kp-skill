# Skill: CoC7_Chase_System

## Role

《克苏鲁的呼唤（Call of Cthulhu 7th Edition）》规则引擎 - 追逐篇。

你的职责不是创造规则，而是严格执行CoC7版官方追逐规则。

当出现以下情况时必须调用本Skill：

* 玩家开始追逐（徒步或载具）
* 建立追逐地图
* 决定追逐者与逃脱者
* 处理追逐移动
* 处理追逐中的冲突
* 判定追逐结束

---

# 第一章：建立追逐

## 1.1 决定追逐者与逃脱者

```text
追逐者（Pursuer）：
  正在追赶的一方
  目标是追上目标

逃脱者（Fugitive）：
  正在逃跑的一方
  目标是拉开距离或彻底逃脱

注意：
  角色可能在追逐过程中因行动而互换角色
```

## 1.2 建立追逐地图

```text
在纸上画出追逐路线

标记：
  追逐者起始位置
  逃脱者起始位置
  沿途障碍物/拐点

距离单位：
  使用"追逐点数（CP）"表示
  起始时双方各有若干CP
  追逐者需将CP追到与逃脱者相同或超越
  逃脱者需将CP拉大到安全距离
```

## 1.3 决定可用技能

```text
追逐中可用的技能取决于追逐方式：

徒步追逐：
  体质（CON）、敏捷（DEX）、攀爬、跳跃、潜行

载具追逐：
  驾驶、汽车驾驶、骑术、操作重型机械

通用：
  侦查、聆听、幸运、智力、力量
```

# 第二章：追逐轮

## 2.1 行动顺序

```text
按敏捷（DEX）降序行动
载具追逐中载具的操控者使用自身DEX
```

## 2.2 每轮行动

轮到角色行动时，必须声明：

```text
移动 —— 尝试缩短或拉大距离
攻击 —— 尝试攻击对方
干扰 —— 制造障碍或分散对方注意力
特殊行动 —— 攀爬、跳跃、冲撞等
```

## 2.3 移动判定

```text
基本移动：
  双方各获得基础CP移动量

成功行动：
  通过技能检定增加CP移动量
  常规成功：+1 CP
  困难成功：+2 CP
  极难成功：+3 CP

失败：
  不增加CP移动量
  可能会失去CP
```

# 第三章：障碍物

## 3.1 设置障碍物

```text
守秘人在追逐地图上预设障碍物：
  矮墙（需跳跃或攀爬）
  转角（需敏捷转弯）
  人群（需潜行或话术通过）
  车流（需驾驶检定通过）
```

## 3.2 通过障碍物

```text
徒步追逐：
  跳跃跨越障碍 → 跳跃或敏捷检定
  攀爬翻越 → 攀爬检定
  绕道 → 损失1 CP

载具追逐：
  急转弯 → 驾驶检定
  穿梭车流 → 驾驶检定（可设困难）
  撞击障碍物 → 伤害+可能失控
```

## 3.3 障碍物失败后果

```text
检定失败：
  受到伤害（跳跃失败摔倒等）
  损失CP
  被障碍物阻挡一回合

大失败：
  严重伤害
  在载具追逐中可能翻车
  在徒步追逐中可能被抓住
```

# 第四章：追逐中的攻击

## 4.1 远程攻击（枪械）

```text
根据双方CP距离判定难度：
  短距离：常规难度
  中距离：困难难度
  长距离：极难难度
  超出范围：无法攻击
```

## 4.2 近战攻击

```text
仅当双方CP距离为0时可以进行近战
处理方式：进入战斗轮（参见 battle.md）
```

## 4.3 干扰行动

```text
投掷物品：
  投掷检定
  成功则目标需做敏捷检定，失败则损失1 CP

设置路障：
  需要合适的物品
  成功则追逐者需做驾驶/敏捷检定绕开
```

# 第五章：追逐结束判定

```text
逃脱者获胜条件：
  逃脱者的CP达到守秘人设定的逃脱阈值
  如：跑出视野、混入人群、到达安全地点

追逐者获胜条件：
  追逐者的CP追平或超过逃脱者
  即：被追上

追逐中止条件：
  连续三轮双方CP无变化
  任意一方主动放弃
  环境变化导致追逐无法继续（如目标进入车流）
```

# 第六章：可选规则

## 疲劳

```text
长时间追逐中：
  每三轮进行一次体质（CON）检定
  失败则所有行动获得一个惩罚骰
  休息一轮可移除疲劳
```

## 奖励骰/惩罚骰

```text
优势情况 → 奖励骰：
  熟悉地形
  更快的交通工具
  人数优势

劣势情况 → 惩罚骰：
  不熟悉地形
  负重过多
  受伤状态
```

# 输出格式

每次追逐轮结算必须输出：

```text
1. 当前追逐者CP / 逃脱者CP
2. 地形/障碍物描述
3. 行动声明
4. 检定结果
5. CP变化
6. 距离变化描述
7. 是否触发结束条件

示例：

追逐状态：
追逐者CP: 3 → 逃脱者CP: 5

行动：
山田拓海跳过矮墙追击

检定：
跳跃 40/40（常规成功）

结果：
CP +1
追逐者CP: 4 → 逃脱者CP: 5

描述：
距离缩小，但仍差一个街区
```
