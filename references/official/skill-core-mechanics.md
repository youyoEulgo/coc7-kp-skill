# Skill: CoC7_Core_Mechanics

## Role

《克苏鲁的呼唤（Call of Cthulhu 7th Edition）》规则引擎 - 核心机制篇。

你的职责不是创造规则，而是严格执行CoC7版官方规则。

当出现以下情况时必须调用本Skill：

* 决定是否要掷骰
* 设定检定难度等级
* 判定成功/失败等级
* 判定大失败/大成功
* 处理孤注一骰
* 处理奖励骰/惩罚骰
* 处理对抗检定
* 处理组合技能检定
* 处理社交技能难度
* 处理幸运检定/智力检定/知识检定/灵感检定
* 处理技能成长（幕间成长）
* 处理花费幸运值（可选规则）
* 处理信用评级与调查员开支
* 处理创建熟人
* 处理训练与技能学习
* 处理老化效果

# 核心原则

所有检定遵循：

```text
是否有必要掷骰？
  ├─ 日常普通事务 → 不需要骰，直接成功
  ├─ 紧张/不确定/有风险 → 需要骰
  └─ 完全不可能 → 不允许检定

↓

设置难度等级（常规/困难/极难）

↓

玩家声明目标后掷骰

↓

比较结果与难度等级 → 成功或失败

↓

如有需要 → 判定成功等级（大失败/失败/常规/困难/极难/大成功）
```

# 第一章：何时掷骰

## 不需要掷骰的情况

```text
调查员做日常普通事务
  例如：驾车前往目的地、买一份报纸、正常走路
  结果：自动成功，故事继续

调查员声明一个合理的行动且没有时间压力或风险
  例如："我要检查门有没有锁"（门没锁）
  结果：直接告知结果
```

## 需要掷骰的情况

```text
行动结果不确定且有紧张感
  例如：在暴雨中驾车逃逸、攀爬一面湿滑的墙壁
  
玩家间出现争议
  例如：一个调查员不相信另一个说的话

面临危险或时间压力
  例如：在怪物追来之前撬开一扇锁着的门

对抗NPC的行动
  例如：潜行绕过守卫
```

## 不允许掷骰的情况

```text
目标完全不可能实现
  例如：跳上月亮、用拳头打碎一堵水泥墙
  
规则：守秘人拥有最终决定权
```

# 第二章：难度等级

守秘人根据任务复杂度设定难度。

## 三级难度体系

```text
常规难度
  要求：骰出 ≤ 技能/属性值
  适用：对胜任者构成挑战的一般情形
  频率：绝大部分情况

困难难度
  要求：骰出 ≤ 技能/属性值的 一半
  适用：对专业人士构成挑战
  频率：偶尔使用

极难难度
  要求：骰出 ≤ 技能/属性值的 五分之一
  适用：触及人类可能性边界
  频率：极端情形才使用
```

## 根据活物设定难度

若调查员面对一个活物（人类或生物）：

```text
对手技能/属性 < 50 → 常规难度
对手技能/属性 ≥ 50 → 困难难度
对手技能/属性 ≥ 90 → 极难难度
```

## 简化裁定

```text
任务感觉很简单 → 免去检定
任务有挑战性 → 常规
任务对专业人士也有难度 → 困难
任务近乎不可能 → 极难
```

# 第三章：成功与失败等级

## 六种检定结果

```text
大成功：骰出 01
  除了达成目标外还有某种有益的事情发生
  由守秘人决定好运的本质（玩家可建议）

极难成功：骰出 ≤ 技能/属性值的五分之一

困难成功：骰出 ≤ 技能/属性值的一半

常规成功：骰出 ≤ 技能/属性值

失败：骰出 > 技能/属性值（但不是大失败）

大失败：骰出 100
  若成功需要的值低于 50，则 ≥ 96 即为大失败
  大失败的冲击立即生效
  不能由孤注一骰无效化
```

## 注意

```text
技能值的不同比例（五分之一、一半、全部）
不意味着成功之间的区别
玩家声明一个目标并且掷骰
若检定结果等于或低于目标值，目标就充分实现了
若结果低于半值或五分之一，并不意味着行动以更高标准实现了
关于检定的任何进一步解释由守秘人决定
```

# 第四章：孤注一骰

## 基本规则

```text
孤注一骰为玩家提供第二次也是最后一次机会尝试实现目标

前提：
  只有合情合理时可以进行
  由玩家主动询问"我能否孤注一骰？"
  
限制：
  只有技能和属性检定可以孤注一骰
  幸运、理智或战斗检定不可孤注一骰
  伤害与理智损失的掷骰不可孤注一骰

时间流逝：
  孤注一骰不是简单的重骰
  时间总是会在检定间流逝——可能是几秒，也可能是几小时

目标状态：
  目标必须仍然可实现
  通常技能与难度等级保持不变
  若局势改变也可相应调整
```

## 成功与失败

```text
孤注一骰：成功
  玩家的目标实现，就如同原本的检定一般运作
  没有失败的后果发生

孤注一骰：失败
  守秘人可以自由支配后果，包括：
    伤害
    理智损失
    装备损失
    与其他调查员隔离
    被抓获
  守秘人甚至可以让玩家的目标实现，但付出某种形式的代价
```

# 第五章：奖励骰与惩罚骰

## 基本规则

```text
适用：
  优势局势、环境、许可的时机都能妨碍或帮助一次检定
  给予奖励骰（有利）或惩罚骰（不利）

注意：
  不是微不足道地增减几个百分点
  只有理由充分时才能使用
  如果一个因素只能影响几个百分点，不要使用

抵消：
  一个奖励骰与一个惩罚骰会互相抵消

叠加：
  绝大多数时候只增减一个
  当情势极其有利或不利时，可以采用第二个
```

## 奖励骰（有利）

```text
投法：
  正常的1d100（一个个位骰+一个十位骰）
  之外再骰一个额外的十位骰
  现在你骰了：一个个位骰 + 两个十位骰

取结果：
  采用会给出较好（较小）结果的那个十位骰

举例：
  个位骰=4，两个十位骰=40和20
  可组合为44和24
  选择较小的24
```

## 惩罚骰（不利）

```text
投法：
  正常的1d100之外再骰一个额外的十位骰

取结果：
  采用会给出较好（较大）结果的那个十位骰

举例：
  个位骰=1，两个十位骰=20和40
  可组合为21和41
  选择较大的41
```

## 难度等级与奖罚骰配合使用

```text
技能检定（单方掷骰）：
  有利/不利因素应当纳入难度等级设置
  奖罚骰与难度等级共同使用应当是特例而非惯例

对抗检定（双方掷骰）：
  没有设置难度等级
  一方达到的成功等级等价于另一方要实现的难度等级
  若有独立作用于其中一个角色的有利/不利因素，给予奖罚骰
```

# 第六章：对抗检定

## 适用场景

```text
两位调查员互相对抗
近战（双方掷骰）
任何双方有互斥目标的情形
```

## 流程

```text
双方都声明互斥的目标：自身胜利，对方失败

双方都选择一项技能或属性来使用（不必相同）
  需经过守秘人许可

双方掷骰并与各自所选技能/属性比较
  得到一个成功等级

比较成功等级：
  大成功 > 极难成功 > 困难成功 > 常规成功 > 失败 > 大失败
  等级高者获胜

若打成平手：
  技能（或属性）更高的一方获胜
  若仍然平手，则达成僵局或者双方都重骰

对抗检定不能孤注一骰
```

## 注意

```text
战斗之外：
  守秘人应当避免在调查员与NPC间使用对抗检定
  当守秘人熟悉规则时，只要能增强戏剧性，可自由使用

属性vs技能：
  属性通常比技能要高
  若一方使用了属性值，另一方应当获得选择属性还是技能的机会
```

# 第七章：组合技能检定

## 适用场景

```text
某些情况允许或要求使用复数技能
```

## 流程

```text
只投一次骰子
将结果与每个技能比较

守秘人说明要求：
  每个技能都成功（结果对每个技能来说都是成功）
  或
  只要任何一个技能成功即可
```

## 举例

```text
需要两个都成功：
  维修一个兼具机械和电气部件的东西
  投一个骰子，比较机械维修和电气维修

只要一个成功：
  通过侦查看到对方伸手掏枪，或通过心理学预测对方行动
  投一个骰子，任意一个技能成功即可
```

# 第八章：特殊检定类型

## 幸运检定

```text
适用：
  外部环境因素主导时
  要决定命运之手的时候
  
注意：
  若有技能或属性适用于此情景，应使用该检定而非幸运检定

团体幸运检定：
  由幸运值最低的玩家来骰

厄运判定：
  若认为队伍中会有一个成员遭遇厄运
  可直接判定具有最低幸运值的调查员遭遇不幸

消费幸运点：见第十三章 花费幸运值（可选规则）
```

## 智力检定（INT）

```text
适用：
  调查员试图破解智力谜题时

方式：
  骰出 ≤ 调查员的智力值 → 成功

举例：
  解决纵横填字谜、回答谜语
```

## 灵感检定

```text
适用：
  调查员卡在某处
  完全错过了一条重要线索
  不知道接下来该做什么
  游戏陷入停滞

方式：
  与智力检定相同——骰出 ≤ 智力值

结果：
  成功：将调查带回正轨
  失败：线索被找到但需要付出代价
```

## 知识检定

```text
适用：
  调查员是否知道某个常识性信息

方式：
  骰出 ≤ 教育值（EDU）→ 成功

注意：
  若有更适当的技能，应使用该技能而非知识检定
```

# 第九章：社交技能难度等级

## 涉及技能

```text
魅惑、话术、恐吓、说服
```

## 设定难度

```text
根据对方的社交技能或心理学技能（取较高者）决定难度：

对方技能 < 50% → 常规难度（≤技能值）
对方技能 ≥ 50% → 困难难度（≤技能值的一半）
对方技能 ≥ 90% → 极难难度（≤技能值的五分之一）

大多数NPC低于50%，所以通常是常规难度
```

## 调整因素

```text
若NPC倾向于支持玩家的目标：
  不用检定，直接同意

若NPC对目标缺乏强烈感受：
  无需调整难度

若NPC强烈反对玩家的目标：
  难度等级增加一到两级

若玩家有切实论据（说服）或握着武器（恐吓）：
  降低一个难度等级

最低成功率情形：
  需要极难成功
  某些罕见情形下守秘人可判定根本没有机会成功 → 不允许检定
```

除了达成目标之外，还有某种有益的事情发生了

守秘人决定好运的本质

```text

```

# 第十一章：复数玩家为一项技能检定掷骰

当多个调查员试图实现同一个目标时：

```text
方式：
  由拥有最高技能值的调查员来掷骰
  每有一位额外的调查员提供帮助，给本次检定增加一个奖励骰

限制：
  只有合理的情况下才能提供帮助
  帮助者需能实际协助行动（例如：一起推动重物）
```

# 第十二章：幕间成长 — 技能成长

## 获得成长标记

```text
当调查员在游戏中成功使用了技能，玩家应该在角色卡上
该技能旁的方框打勾（标记）。

限制：
  - 若使用了奖励骰则不能获得技能成长标记
  - 对抗检定双方都成功时，只有胜者可以获得技能成长标记
  - 克苏鲁神话（CM）与信用评级（CR）永远不会获得技能成长标记
```

## 进行成长检定

幕间成长在场景结束时进行（战役中则在章节总结时）。

```text
1. 查看角色卡有哪些技能具有成长标记
2. 无论一项技能成功了几次，每个技能只有一次成长检定的机会
3. 对每个标记的技能，玩家骰 1D100：

若骰出 > 当前技能值（或结果 > 95）：
  调查员从经验中获益
  骰 1D10 并将结果加到当前技能值上
  技能可以通过此方式超过 100%

若骰出 ≤ 当前技能值：
  调查员未能从此经验中学到什么
  技能值不改变

4. 擦去角色卡上所有成长标记
5. 下次游戏时若成功使用了技能，则能再次获得成长标记
```

## 技能达到90%或更高

```text
在幕间成长中，若调查员有技能达到了 90%或更高，
为他当前理智点增加 2D6 点。
这表示经过磨练从精通一项技能中获得了自信。
```

## 幕间成长中的其他活动

```text
在幕间成长中，调查员也有机会：
  - 花费时间于自身背景相关的某方面以获得理智点（自救）
  - 检查信用评级并回顾经济状况（见第十四章）
  - 减少1点理智点限制（习惯恐惧）
  - 修改或增添背景故事一栏
  - 在守秘人允许时消除或修改损伤与伤痕、恐惧与狂躁
  - 修改调查员的关键连接
```

# 第十三章：花费幸运值（可选规则）

## 基本规则

```text
时机：
  在玩家进行技能检定（使用技能或属性）后

比例：
  1:1 — 每花费1点幸运，掷骰结果减1

扣除方式：
  花费的点数从玩家的幸运值中扣除，永久减少
  
上限：
  可在一次检定中花费任意数量的幸运值（上限为当前幸运值）
```

## 限制

```text
不可用于：
  ❌ 幸运检定本身
  ❌ 伤害检定  
  ❌ 理智检定（SAN检定）
  ❌ 决定理智损失的掷骰
  ❌ 大成功(01)、大失败(100)与火器故障（这些总是要应用）

与孤注一骰的关系：
  ❌ 孤注一骰的结果不能用幸运值改变
  ⚠️ 技能检定失败时，玩家只能在"孤注一骰"和"花费幸运"中二选一
```

## 其他代价

```text
若使用了幸运值来改变检定结果，不会获得技能成长标记。
```

## 幸运回复

```text
在接下来的几次游戏开始时，玩家作幸运回复检定：
  骰 1D100
  若结果 > 当前幸运值，骰 1D10 加到幸运值上
  
举例：
  哈维幸运降低到15。他骰出37（>15），增加1D10→7，
  幸运回复到21。
```

# 第十四章：信用评级与调查员开支

## 生活标准与消费限额

```text
调查员在角色建立时决定起始信用评级（CR）。

日常开支：没必要为住宿、食物、临时旅行花费开账单。
只要调查员的开支在生活标准范围内（参见CR），
角色在每一天都能花费他或她的消费水平的钱。

消费限额（CR为基础）：
  例如 CR 41（标准）→ 每天可花费 $10
```

## 超出消费限额

```text
当调查员花费超出了消费限额时，玩家必须全额减少现金。
若现金不足，调查员可以寻求使用其他资产。
将其他资产转换为现金要花费时间。
```

## 信用评级的改变

```text
增加：
  信用评级可通过成功使用该技能，或作为杰出事迹的奖赏，
  或经过不屈不挠的努力而增加。

减少可能的原因：
  - 勒紧腰带：调查员被降职或无薪离职 → 降低 1D10
  - 变卖家产：花费其他资产的绝大部分 → 降低 1D10
  - 厄运缠身：失去主要收入来源 → 每次幕间成长降低 2D10
  - 失败破产：突然失去全部收入 → 降低 1D100
  
注意：信用评级最低为 0（负数忽略）
```

# 第十五章：熟人

调查员可能希望利用个人与专业上的熟人。

## 创建熟人

```text
玩家骰最适合的技能或属性来创建熟人：
  化学 → 认识一位化学家
  医学 → 认识一位外科医生
  其他技能类推

成功意味着 NPC 听说了调查员（通过声誉）
或是调查员曾经与其相识。

地点是重要因素：
  远离家乡或人烟稀少 → 增加难度等级
  在家乡找同专业熟人 → 降低难度等级
```

## 注意事项

```text
创建熟人不意味着他就会如调查员所愿而行动。
仍然需要某种说服、话术、魅惑或恐吓，以及相应的扮演。

若玩家希望孤注一骰创建熟人，守秘人应当暗骰
（在玩家视野之外），因此玩家不知道检定结果。
孤注一骰失败的建议后果：让调查员无意中遭遇
一个敌对或不可靠的熟人。
```

# 第十六章：训练

```text
条件：
  提供足够的钱，会有人愿意教授任何东西

时间：
  调查员可以学习四个月
  随后玩家对那项技能作技能成长检定：
    骰 1D100
    若骰出 > 当前技能值，增加 1D10

限制：
  每四个月的游戏内时间，在同一项技能内
  习得不超过 1D10 的点数。
  由守秘人决定是否能同时进行多项课程。

战斗技能：
  由于战斗技能（如剑术）如此罕见，
  学校和私人教练是仅有的学习方式。
```

# 第十七章：老化

老化效果是累加的。

```text
达到 20 岁：
  EDU 进行 1 次增强检定
  STR、SIZ 合计增加 5 点

达到 40 岁：
  EDU 进行 1 次增强检定
  STR、CON、DEX 合计减少 5 点
  APP 减少 5 点
  MOV 减少 1 点

达到 50 岁：
  EDU 进行 1 次增强检定（40岁和50岁分别各一次）
  STR、CON、DEX 合计减少 5 点（加上40岁的减少，共10点）
  APP 减少 5 点（累加共10点）
  MOV 减少 1 点（累加共2点）
```

注意：老化也可能作为法术或魔法门的结果而突然发生，这类老化会造成负面物理效果但不会获得教育提升。

# 输出格式

每次检定结算必须输出：

```text
1. 行为描述
2. 检定类型
3. 骰出结果
4. 难度等级
5. 成功等级
6. 结果描述
7. 数值变化（如有）

示例：
行动：
林夜尝试观察便签细节

检定：
侦查 30/70（成功）
难度：常规

结果：
发现便签背面隐约有字
```
