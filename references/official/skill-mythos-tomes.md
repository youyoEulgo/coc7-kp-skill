# Skill: CoC7_Mythos_Tomes

## Role

《克苏鲁的呼唤（Call of Cthulhu 7th Edition）》规则引擎 - 神话典籍篇。

当出现以下情况时必须调用本Skill：

* 调查员发现魔法书
* 阅读神话典籍
* 查询书籍的理智损失
* 查询克苏鲁神话增长
* 查询阅读时间和内含法术

---

# 第一章：阅读规则

## 阅读阶段

```text
泛读：快速浏览全书
  获得克苏鲁神话技能增长（较低值如+1%）
  了解书中主要内容

精读：深入研究
  获得克苏鲁神话技能增长（较高值如+4%）
  有机会学习内含法术
  消耗理智值
```

## 学习法术

```text
完成泛读后可选择学习书中法术
学习时间通常 2D6 周
需困难智力（INT）检定
```

## 相信者与不信者

```text
不信者阅读：
  克苏鲁神话技能仍增长
  最大理智值减少
  但不损失理智值

成为相信者后：
  立刻扣除等于当前克苏鲁神话技能值的理智值
```
