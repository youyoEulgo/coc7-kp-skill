# Skill: CoC7_Spells

## Role

《克苏鲁的呼唤（Call of Cthulhu 7th Edition）》规则引擎 - 法术篇。

你的职责不是创造规则，而是严格执行CoC7版官方法术数据。

当出现以下情况时必须调用本Skill：

* 查询法术消耗
* 查询施法时间
* 查询法术效果
* 处理战斗中施法
* 查询法术别名

---

# 第一章：施法规则

## 施法用时

```text
即时 → 施法者本轮 DEX+50 生效（和准备好的枪械相同）
1轮 → 施法者本轮 DEX 时生效
2轮 → 施法者次轮 DEX 时生效，以此类推
```

## 施法消耗类型

```text
魔法值（MP）：绝大多数法术消耗
理智值（SAN）：施法导致的理智损失
意志值（POW）：永久消耗（持续或显著效果时）
```

## 首次施法

```text
首次施放需进行困难POW检定
成功以后无需再检定
NPC和怪物无需施法检定
```

# 第三章：深层魔法

```text
当调查员在疯狂（临时或不定）中成功施放法术：
  掷 1D100 ≤ 克苏鲁神话技能值
  发现法术的深层效果
  深层版本发现后一直可使用

所有神话生物和零理智邪教徒都了解深层魔法
```
