# Skill: CoC7_Magic

## Role

《克苏鲁的呼唤（Call of Cthulhu 7th Edition）》规则引擎 - 魔法篇。

你的职责不是创造规则，而是严格执行CoC7版官方魔法规则。

当出现以下情况时必须调用本Skill：

* 调查员学习法术
* 调查员施放法术
* 阅读神话典籍获取法术
* 处理魔法值消耗
* 处理施法代价
* 处理"不信者"与"相信者"的转换
* 处理POW增长

---

# 第一章：魔法概述

## 魔法本质

```text
克苏鲁神话的魔法源自外星智慧
被人类解释为"魔法"
魔法是危险的，使用魔法会将调查员引向疯狂
```

## 关键概念

```text
调查员极少成为魔法师
通常在了解必要的知识和技能之前就发了狂
神话魔法需正规施放，一个词或手势的错误就可能导致可怕的后果
能快速施放的法术寥寥无几，很多需要苛刻条件和冗长仪式
```

# 第二章：魔法值（MP）

## 魔法值计算

```text
魔法值（MP）= 意志值（POW）÷ 5

正常调查员初始MP = POW/5
邪教徒和强大巫师可能拥有更多MP
```

## 魔法值消耗

```text
施放法术时通常必须消耗MP
激活魔法造物、为魔法通道充能也需要MP
MP消耗殆尽后，所有额外的消耗从HP中扣除
```

## 魔法值恢复

```text
自然恢复：每天恢复POW/5的MP
休息和睡眠可加速恢复
```

# 第三章：学习法术

## 从神话魔法书中学习

```text
先决条件：
  调查员至少对魔法书进行过泛读

选择法术：
  KP指出法术的存在（使用描述性名称而非规则名称）
  如"于虚空中生出一有翼巨兽"而非"拜亚基召唤术"

学习时间：
  通常2D6周（由KP裁定）
  可开始、中止再开始

学习检定：
  困难难度的智力（INT）检定
  若失败则学不会

孤注一骰：
  可孤注一骰，但需合理解释（如闭关不学会不出来）
  失败后果：理智值损失、怪异魔法效果

无时间压力：
  不需孤注一骰，可继续学习
  下次检定由KP裁量（可每两周一次）
```

## 从他人处学习

```text
一对一的教导比从书中学更快
通常1D8天可以学会一个法术
其他规则与从书中学习相同
```

## 从神话存在处学习

```text
神话生物提供书籍或卷轴
通过梦境和幻象传授知识
每次经历消耗理智和意志
可短可长，由故事需要决定
神话存在通过心灵感应直接灌输
SAN 0/1D6（灌输方式）
```

# 第四章：施放法术

## 首次施放

```text
首次施放需进行困难POW检定

若成功：
  法术成功施放
  以后使用不再需要施法检定

若失败：
  可能无法施放
  可孤注一骰

NPC和怪物无需进行施法检定
```

## 施法消耗

```text
魔法值（MP）消耗：
  几乎所有法术都需要消耗MP
  不足时从HP扣除

理智值（SAN）消耗：
  使用克苏鲁神话力量导致理智损失
  数量依法术不同

物理成分消耗：
  某些法术需要物理成分
  有些可反复使用（如召唤用的巨石）
  有些会消耗掉（如黄金蜂蜜酒）

施法时间：
  可即时生效
  也可需要数秒、一分钟、一周甚至更长
```

## 施法动作

```text
施法者必须知晓法术
用威严语调背诵颂歌或仪式
手势可能非常重要
施法者通常需完全的行动自由
```

# 第五章：相信者与不信者

## 不信者

```text
调查员有权选择不相信神话
阅读神话书籍时不损失理智值
克苏鲁神话技能仍增长，最大理智值仍减少

成为相信者的条件：
  目击神话存在的直接证据
  目睹明显来自异界的生物
  目击神祇化身
  理智检定失败

成为相信者后：
  立刻扣除等于当前克苏鲁神话技能值的理智值
  可能触发临时疯狂
```

## 相信者

```text
遭遇食尸鬼等生物后，发现书中知识是真的
除目击理智损失外，额外损失等于当前CM技能值的SAN
```

# 第六章：POW增长

## 施法获胜增长

```text
成功施放需要POW对抗检定的法术
施法者在POW对抗中获胜
可尝试提升POW
  
检定：1d100 > 施法者POW（或≥96）
成功：POW永久提升1D10
```

## 幸运01增长

```text
任何幸运检定结果为01时
作为奖励掷1d100
若结果 > POW（或≥96）
POW永久提升1D10
```

# 第七章：克苏鲁神话技能使用

## 使用规则

```text
克苏鲁神话技能不获得成长标记
每次使用克苏鲁神话技能达成指定目标都需要检定
孤注一骰失败的消耗和结果与施法检定相同
若孤注一骰失败，KP可能允许达成目标，但这不是必然的
```

## 使用实例

```text
识别神话生物
解读神话符号
回忆神话知识
理解法术效果
```
